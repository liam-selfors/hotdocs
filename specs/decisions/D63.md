# D63 — Criterion test filename: a shared, deterministic formula, promoted to the glossary

## Context

Two independent components (criterion-compiler's own compiled output, test-author's real implementation) already used the identical filename formula for a criterion's executable test file, but it had never been written down as a cross-component rule anywhere a dependent's bundle would surface it — only implied by one illustrative example in a schema doc. Two independent real candidates for a third, dependent component each invented a different, incompatible scheme for checking it, confirming the gap was real.

## Decision

The formula (`test_<criterion_id, lowercased, '-'->'_'>.py`, directly under `verification/<component>/<kind>/`, no nesting, no hash suffix) is now a named glossary entry, cross-referenced from both producing components' own requirements and from the dependent's cache-check requirement.
