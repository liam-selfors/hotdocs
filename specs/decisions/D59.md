# D59 — criterion-compiler's compile_criterion primitive

## Context

`capability-scenario-verifier`'s real build needed `kind: compiled` dispatch for criteria that live outside any single component's `acceptance/` directory — a capability scenario spans the whole assembled system, with no one component's `interface/` to resolve against. `criterion-compiler`'s only public entry point, `compile()`, was hardcoded to scan one component's own `acceptance/` directory, and no new dispatch machinery was allowed as a workaround.

## Decision

`criterion-compiler` (sealed) gains a new, directory-scanning-free primitive, `compile_criterion(criterion, surface=None)`, that `compile()` now uses internally for each criterion it finds, and that any caller can use directly for content outside a component's `acceptance/`. `surface=None` is a real, valid input — a step that still references a function/type with none supplied is a located compile error, never silently skipped for lack of a surface.
