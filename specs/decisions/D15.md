# D15 — Two size-cap dimensions crowding their warn thresholds for the same component at once is a real decomposition signal

## Decision

When two or more independent size-cap dimensions (word count, fan-out, generated LOC, requirement/acceptance count, etc.) are over their *warn* threshold for the same component simultaneously, `spec-linter` emits one distinct warning naming which dimensions — advisory, never a hard failure, deliberately keyed off *warn* so the signal surfaces before a hard-fail forces the question. This means the component isn't just calling a lot of neighbors, it's also carrying enough decision logic to show up in word count too — the fix is to find that logic's own identity and extract it, not to raise the cap.
