# D336 — Capability scenario tests find the real compiler through a dependency's directory

## Context

`capability-scenario-verifier`'s tests copy the real criterion compiler
"from the live repository", which the interface never located. Tests
re-authored for `D334` walked up from the module's own file or the test
file to a directory holding `pipeline/criterion-compiler/`. That works
in the criterion run, but a mutation run copies only `gen/<slug>/` into
a fresh directory (`D324`), so three of five seeds failed the mutation
baseline and the other two skipped the compiler's scenario.

## Decision

The interface's fixture rules move to
`specs/architecture/capability-scenario-fixtures.md`, which the
interface implements. It names the tree to copy the compiler from: the
one holding the `gen/llm-endpoint/` directory beside the module's own,
resolved through its link in a mutation run, so both runs reach the same
compiler. A test never skips for a missing compiler, and one that
compiles nothing supplies none. The shapes are unchanged.

## Consequences

`capability-scenario-verifier` regenerates. Nothing depends on it, so
nothing else misses.
