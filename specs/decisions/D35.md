# D35 — Tool/context isolation for a CLI-dispatched model call is structural

## Decision

Every `claude`-CLI dispatch passes `--tools ""` (disables all tool access) and `--bare` (skips `CLAUDE.md`/hooks/memory/settings auto-discovery) unconditionally. A system prompt instructing the model not to explore is a request, not a barrier — isolation must be enforced structurally, the same distinction already drawn for credential handling.
