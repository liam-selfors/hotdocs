# D61 — realizes edges are declared per-component, never per-capability

## Context

The `realizes:` frontmatter field exists only on a component's own `component.md`, never on the product capability file it names. A local, bundle-free fallback for building the equivalent edge set got this backward independently, twice, across two separate real candidates — confirming a genuine ambiguity rather than a one-off mistake.

## Decision

Building this edge set locally means scanning every component's own `component.md` for its `realizes:` list, never scanning capability files for a field that doesn't exist on them. Stated explicitly in the relevant requirement text rather than left implicit.
