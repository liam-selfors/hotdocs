# D265 — `impact-analyzer`'s bundle carries `SPEC_GUIDELINES.md`

## Context

`R-IMPACT-007` refuses a corpus that does not lint clean, so every test
of `impact-analyzer` must build a lint-clean corpus. Seed 1's tests
wrote guarantee files without an RFC 2119 keyword, which `R-LINT-017`
fails, and the candidate rightly refused them. The rules those tests
needed are in `SPEC_GUIDELINES.md`, which the bundle did not include.

## Decision

`interface/library.md` says a corpus under test must lint clean, gives
the guarantee example, and adds `Implements: SPEC_GUIDELINES.md`
(`R-ASSEMBLE-014`), so the guidelines enter the bundle.

## Consequences

`impact-analyzer` is regenerated.
