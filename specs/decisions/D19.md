# D19 — merge-tracker persists full per-attempt detail, separately from the flattened attempt summary

## Decision

One full-detail record per component per merge attempt — the complete generation result and, if reached, the complete verification report — is written to a separate, local store from the flattened end-of-merge summary. This is the detail a human reads when the summary says "blocked" and they need to know why; writing it never alters the merge outcome itself, for either outcome.
