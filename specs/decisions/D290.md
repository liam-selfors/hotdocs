# D290 — The docs site lays out its DAG in the browser

## Context

With `D289`'s criteria, seed 5 of `docs-site-renderer` still scored
0.59 on mutation. Nearly every survivor was SVG layout arithmetic, pixel
offsets and spacing the candidate computed in Python, which no spec can
or should pin and so no test kills.

## Decision

`interface/library.md` says the DAG view's node and edge elements carry
no coordinates: a script embedded in the page lays them out and filters
them in the browser, so the Python code computes no layout. The view
stays interactive, clickable and searchable (`R-DOCS-001`).

## Consequences

`docs-site-renderer` is regenerated.
