# D275 — An unsealed verifier fixture also declares a capability

## Context

With `D274`'s fixtures unsealed, seed 3 of `verifier-orchestrator`
failed four criteria whose tests first assert the fixture lints clean:
an unsealed component needs `realizes` (`R-LINT-006`), and the fixtures
had none.

## Decision

`interface/library.md` says an unsealed fixture component declares
`realizes: [P-<ID>]` and writes that capability's file.

## Consequences

`verifier-orchestrator` is regenerated.
