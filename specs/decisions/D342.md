# D342 — The JavaScript mutation criterion pins the tokenizer's rules

## Context

`AC-VERIFY-026` checked `D335`'s JavaScript mutants with one string
holding three tokens and a test that killed all of them, so a score of
1.0 also came from finding no sites at all. Three regenerations of
`verifier-orchestrator` passed every criterion and scored 0.70 to 0.78
against the 0.8 bar: 15 of seed 3's 51 mutants survived, nearly all in
the tokenizer (skipping strings, escapes and comments, reading only
`<script>` text, the detection pattern, the unary `-` rule), which no
criterion exercised.

## Decision

`AC-VERIFY-026`'s first scenario uses three strings: one with operators
inside a quoted string with an escaped quote and inside both comment
forms, one HTML page with operators outside and inside `<script>` and a
unary `-`, and one that is not JavaScript. Only the first is asserted,
so the exact score, 1/3, counts the sites in all three. The rules in
`specs/architecture/mutation-runs.md` and `GATE_VERSION` are unchanged.

## Consequences

`verifier-orchestrator` is regenerated; its tests for other criteria
are unaffected.
