# D228 — `AC-ENDPOINT-010` sets the key it needs, and the pasted-key refusal is worded

## Context

Seed 6 of `llm-endpoint` failed two criteria. `AC-ENDPOINT-010`'s test
called `check_connection("openai", ...)` without `OPENAI_API_KEY`, and
`D221`'s rule rightly returned an `auth` error with no call. And a test
expected the secret-entry phrase for a different refusal, an
`api_key_env` holding a key's value, whose message the interface never
gave; the hand-maintained tests expect `never the key itself`.

## Decision

`AC-ENDPOINT-010` sets `OPENAI_API_KEY` first, and `interface/library.md`
gives the pasted-key refusal's phrase.

## Consequences

`llm-endpoint` is regenerated.
