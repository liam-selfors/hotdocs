# D52 — `llm-endpoint`'s timeout floor, found by a real failure

## Context

Attempting to use the real `generator` to regenerate itself (the
natural next self-hosting step after `D51`) failed immediately: the
self-hosted `llm-endpoint`'s own `AnthropicBackend` chose a 120-second
client-side timeout, and `generator`'s own `SpecBundle` — three real
dependencies, meaningfully larger than `llm-endpoint`'s own
dependency-free bundle — didn't complete within it. The call returned
cleanly as a `timeout`-category `model_call_error`, exactly as
`R-ENDPOINT-004`/`R-GEN-008` specify — this was the error-handling path
working correctly, not a bug, but it still meant no candidate was
produced.

`R-ENDPOINT-004` never pinned a concrete bound, deliberately, "because
no second backend exists yet to resolve it against" — but it also never
anticipated that *one* backend's own chosen bound could be too short for
a realistically-sized component's own bundle, found only by actually
attempting one.

## Decision

`R-ENDPOINT-004` now states a concrete floor: **at least 300 seconds** —
a floor other backends/tuning may raise, never lower. This is a spec
change flowing underneath an already-generated component, exactly the
scenario this corpus's whole self-hosting mechanism (`D51`) exists to
handle: `llm-endpoint` was regenerated a second time, through the same
real `generator`/`llm-endpoint` pair `D51` validated, reflecting this
one spec change. Verified against every `AC-ENDPOINT-*` criterion again
(all pass — the behavioral contract is unchanged, only the bound), and
against the real failure case this decision exists because of: a fresh
`generator`-regenerating-itself attempt, this time completing within
the new bound.

## Consequences

This is the first instance of the full loop the self-hosting mechanism
is for: a real spec change, authored by a human, flowing through to a
new generated implementation with no hand-written code in between —
verified, not assumed, by the exact failure this decision documents and
the regeneration that followed it.
