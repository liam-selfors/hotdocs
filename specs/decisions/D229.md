# D229 — `AC-COMPILE-015` builds its own `pipeline/` fixture, and a dotted function name matches exactly

## Context

Seed 13 of `criterion-compiler` failed two criteria. `AC-COMPILE-015`'s
test asserted that the module under test lives under `pipeline/`, but a
sealed component is generated and verified under `gen/` in its sandbox
(`D206`) and only installed at `pipeline/` afterwards. And a test called
`widget.build` while its fixture declared `build`; the grammar allowed
dots in a name without saying what they match.

## Decision

`AC-COMPILE-015` copies the module's own source into a fresh
`pipeline/criterion-compiler/` and checks the algorithm loads that copy.
The grammar says a dotted name matches only a function declared under
exactly that name.

## Consequences

`criterion-compiler` is regenerated.
