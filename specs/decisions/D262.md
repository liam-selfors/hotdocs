# D262 — `decision-drift-detector` loads the views once per call

## Context

Seed 3 of `decision-drift-detector` opened the views twice in one
`find_decision_drift` call, once for edges and once for lineage.
`AC-DRIFT-004` counts exactly one `load_views` call, but only that
criterion said so.

## Decision

`interface/library.md` says each call opens one connection and calls
`load_views` on it exactly once.

## Consequences

`decision-drift-detector` is regenerated.
