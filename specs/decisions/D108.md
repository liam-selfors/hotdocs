# D108 — author_test must not forward seed to the real backend call

## Context

With `D107`'s fix landed and the hand-maintained suite at 18/18 plus the new `AC-AUTHOR-002` gate, the next real `spec-bundle-assembler` bootstrap retry failed all 14 criteria identically — not a lint-cleanliness or assertion failure, but a generic backend error, `{'category': 'network', 'message': 'backend call failed (exit code 1)'}`, on every single `generated-test` authoring. A second identical retry reproduced the exact same uniform failure, ruling out a transient network blip.

Diagnosis: `test_author.py`'s call to `llm_endpoint.complete()` passed `seed=seed` as a keyword argument. `llm_endpoint.complete()` forwards every keyword argument verbatim to the resolved backend (`R-ENDPOINT-001`, by design — it neither interprets nor validates them), and the real `AnthropicBackend` turns each into a CLI flag for the underlying `claude` CLI. `--seed` is not a flag that CLI recognizes, so every real (non-mocked) call failed immediately with a non-zero exit code; every `AC-AUTHOR-*` criterion in the hand-maintained suite is verified against an injected `MockBackend` that accepts and silently ignores arbitrary keyword arguments, so this was invisible there — the same blind spot `D94` first identified for a different reason. `generator`'s own call to `complete()` passes only `prompt`, `model`, `backend` — confirmed directly, and confirmed as the one difference that matters, by reproducing `complete()`'s real call outside the harness with and without the extra `seed` kwarg.

## Decision

New `R-AUTHOR-019`: the call to `llm_endpoint.complete()` MUST pass only `prompt`, `model`, and `backend`, mirroring `generator`'s own call exactly, and MUST NOT forward `seed` or any other of `author_test`'s own bookkeeping parameters — `seed` is a cache-key input only (`R-AUTHOR-004`), never a real model-call parameter. New `AC-AUTHOR-019`, plus two tests added directly to the hand-maintained suite closing the same blind spot found here: a spy-backend check that `seed` is never in the forwarded kwargs, and (closing a gap discovered as this fix was written) dedicated tests for `AC-AUTHOR-017`/`018`, which had specs but no hand-maintained test yet.

`test_author` is cold-regenerated against this amendment; `spec-bundle-assembler` is retried once more.
