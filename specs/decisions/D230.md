# D230 — `AC-ENDPOINT-001` resolves without an injected backend

## Context

Seed 7 of `llm-endpoint` failed three criteria. `AC-ENDPOINT-001`'s test
injected a mock backend and expected resolution errors, but an injected
backend bypasses resolution by design (`D223`). A test read the
`User-Agent` header under that spelling, where `urllib` stores
`User-agent`. The third, a refusal message missing its phrase, was the
candidate's.

## Decision

`AC-ENDPOINT-001` calls `complete()` with no backend. Every refusal of an
`api_key_env` value, not only a pasted key's, carries `never the key
itself`: seed 8's test passed a value that failed the name check first.
And the header note
in `interface/library.md` names `User-agent` too, in fewer words overall.

## Consequences

`llm-endpoint` is regenerated.
