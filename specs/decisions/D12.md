# D12 — License/secret scanner reference data must come from a maintained external source, never a frozen spec snapshot

## Decision

Both `license-scanner`'s and `secret-scanner`'s reference data (license fingerprints, secret-pattern shapes) MUST be sourced from a maintained, continuously-updated external reference set — never raw text vendored once and frozen into the spec, since fingerprints for active projects change as those projects evolve. No `specs/vars/` declaration for "which external source" — that's a vendored-dependency choice, not a per-environment deployment parameter.
