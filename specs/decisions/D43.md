# D43 — kind:compiled requires actual conformance to the step-phrase grammar, checked before labeling

## Context

Beginning real implementation of `criterion-compiler` found that 0 of 200 existing `kind: compiled` criteria across every already-built component actually conformed to the grammar they claimed — every one was in fact hand-verified the same way a `generated-test` criterion is, with no mechanical compilation step ever involved. `compiled`'s whole trust argument (nothing agent-generated between the criterion and the check) had never actually applied to any shipped criterion.

## Decision

All 200 reclassified to `kind: generated-test`, a metadata-only correction matching how each was actually verified. `kind: compiled` remains available and meaningful for any criterion genuinely authored in the grammar going forward.
