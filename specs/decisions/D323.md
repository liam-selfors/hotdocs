# D323 — hotdocs verify reports components without a model

## Context

`hotdocs verify` raised a usage error as soon as a capability needed a
fresh run and no `--model` was given, before reporting any component,
although the component half is a read-only provenance check. In a
project still being built, no command answered "which components are
current?" (issue #7).

## Decision

Without `--model`, a capability that needs a fresh run is reported not
ready as `<capability_id>: needs a fresh run; pass --model`, nothing
more is run for it, and every component is still checked and reported.

## Consequences

`hotdocs verify` always reports; it exits `1` while a capability waits
for a model run.
