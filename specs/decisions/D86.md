# D86 — Making the promotion criterion explicit, and closing the citation-resolution gap the same way two prior fixes already did

## Context

This session found the same gap class nine separate times (`D61`,
`D62`, `D65`, `D67`, `D69`, `D76`, `D80`, `D82`, `D83`): a convention,
file-path formula, or callable contract that a second component
needed was never promoted to `specs/glossary.md`, so each affected
component independently guessed — sometimes compatibly, sometimes
not. Every one of those nine fixes added the missing fact to the
glossary *after* a real failure or a proactive audit found it, but
nothing in `SPEC_GUIDELINES.md` ever stated a positive rule for *when*
to promote a fact in the first place — only a consumption rule
("specs MUST use glossary terms as defined") with no corresponding
promotion rule.

Separately, this session's own citation-fixing practice (quoting a
glossary entry's bolded header, e.g. `` the glossary's "Criterion test
filename" ``) had quietly become a real, consistent convention without
ever being checked. `R-LINT-026` and `R-LINT-027` already mechanically
validate the two other citation shapes this corpus uses (`D<N>`
decision references, `` `<file>`'s "<Section>" `` section pointers) —
a glossary-term citation was the one shape with no equivalent check.

## Decision

Added an explicit promotion criterion to `SPEC_GUIDELINES.md` §3.6: a
convention **MUST** be promoted to the glossary as soon as a second
component states it, relies on it, or would need to independently
guess it — framed as the sibling discipline to §10's existing
"single source of truth for computed facts" rule, extended from
*calculations* to *shared vocabulary and contracts*.

Added `R-LINT-028`/`AC-LINT-028`: every glossary-term citation must
resolve to a real bolded entry, mirroring `R-LINT-026`/`027`'s
mechanism exactly. This is explicitly scoped as a citation-drift
guardrail, not a promotion-gap detector — the new `SPEC_GUIDELINES.md`
paragraph makes clear that the judgment call (should this be promoted
at all) stays a judgment call, not something a text-matching rule can
make for an author.

## Consequences

Closes the loop on a gap this session paid for nine times over, but
only the *citation-hygiene* half of it — the actual discipline (check
the glossary before writing a cross-component-dependent fact, promote
it if missing) still depends on whoever is authoring or auditing a
spec actually doing it, the same way `R-LINT-026`'s existence doesn't
stop someone from forgetting to write the decision record a citation
points at in the first place. Worth revisiting whether a genuinely
mechanical promotion-gap detector is possible once more real-world
instances accumulate past this session's nine; no such mechanism was
designed here; this is the practical ceiling for a spec-linter-only
fix.
