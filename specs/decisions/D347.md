# D347 — impact-analyzer states which guarantee files count, its default branch and its CLI output

## Context

A regeneration of `impact-analyzer` passed 13 of 14 criteria and scored
0.73: `AC-IMPACT-008b`'s test author never saw `R-IMPACT-010`'s
definition of "the prior commit", and 22 mutants survived in behaviour
no text stated (which files are guarantees, the default branch, the
order of the report, the CLI's flags and text output).

## Decision

A guarantee file is a `G-*.md` file directly in `interface/guarantees/`,
its id the file stem; a `README.md`, another file type or a file in a
subdirectory is not one, and an added or removed guarantee file counts
as changed. The default branch is `origin/HEAD`'s target, else `main`,
else `master`; with none, or no merge-base, every compared file counts
as added. The report lists `direct` entries first, then the rest, each
sorted by component id. The CLI's flag forms and one-line-per-entry
text output are stated in `interface/cli.md` and `R-IMPACT-011`. A
`testing.md` gives every test author the git fixture recipe.

## Consequences

`R-IMPACT-008` narrows "any file under `interface/guarantees/`" to
guarantee files, so editing a guarantees `README.md` no longer impacts
dependents. `impact-analyzer` regenerates.
