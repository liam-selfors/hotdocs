# D33 — llm-endpoint dispatches via the claude CLI's non-interactive mode

## Decision

`complete(prompt, model, *, backend=None, **params) -> ModelResponse`. Model-to-backend resolution is a plain naming-pattern match (`claude-*` → Anthropic), raising immediately for anything unsupported. The Anthropic backend dispatches via a bounded `claude -p --output-format json` subprocess call, classified into exactly one of `network`/`auth`/`rate_limit`/`timeout`. The credential is never read by this module — the subprocess inherits it directly from the environment.
