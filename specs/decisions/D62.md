# D62 — criterion-compiler emits qualified imports, and documents the execution contract this creates

## Context

Every `When ... is invoked` step and typed `Given` step compiled to a bare, unqualified call with no import of the target module — never caught before because no prior test of the compiler's own output ever executed the emitted test as a real running test against real target code, only checked its content.

## Decision

Emitted test code now imports and qualifies every resolved function/type reference by the target module's name, emitting exactly one top-level import line when any step needs it. This creates a real execution-environment contract for any caller that runs emitted output: the import search path must be scoped to the specific `gen/<component>/` directory, never a broader ancestor — a broader scope resolves the import as an empty implicit namespace package instead of the real module.
