# D261 — `R-CITE-004` exempts `D1`–`D14`; the `R-LINT-015` judge contract

## Context

Spec-linter's hand suite, run against seed 2, found two gaps. The
landed `citation-checker` reports `supersedes: D5` as unresolved,
though its Definitions say `D1`–`D14` always resolve and `R-CITE-005`
exempts them explicitly; `R-CITE-004` did not. And the candidate read
the `judge` callable's boolean as "consistent", where the hand version
and its tests read "conflicts": no spec text gave the contract.

## Decision

- `R-CITE-004` exempts `D1`–`D14` from its resolution and status checks.
- `interface/library.md` gives `judge(term, local_text, glossary_text)`
  returning `(conflicts, rationale)`, or `None` for `skipped`.

The hand test that matched `R-CITE-004` message wording now checks only
the decision ids each finding names, since wording is not specified.

## Consequences

`citation-checker` and then `spec-linter` are regenerated.
