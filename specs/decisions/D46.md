# D46 — Generated output must be a flat module or a top-level package, never deeper

## Context

A real candidate for `provenance-checker` produced a full installable `src/`-layout package. `spec-bundle-assembler`'s real dependency-usage introspection only ever looks for a dependency's code at `gen/<slug>/<module>.py` or `gen/<slug>/<module>/__init__.py` — a `src/` layout matches neither, and would silently (by design) return nothing to any future dependent.

## Decision

`generator`'s own prompt instructs every candidate to lay its output out as a flat module or a top-level package, never deeper — a cross-cutting output-format instruction, not bundle content, so it reaches every future call regardless of which component is being generated.
