# D68 — A deliberately uncached dispatch can be the correct design, if documented as such

## Context

A real, working component's dispatch logic never checks a cache file before invoking its downstream authoring callable, unlike an analogous sibling component that does — undocumented, reading as a possible oversight rather than a decision.

## Decision

Documented as deliberate: there is no natural per-unit path to anchor a cache file to for content that spans more than one unit, and the downstream callable already checks its own cache internally before any expensive call — so a repeated dispatch for unchanged content is already a fast cache hit one layer down. Not a real inefficiency; just needed to be written down as the considered answer it was.
