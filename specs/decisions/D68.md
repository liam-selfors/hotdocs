# D68 — Second real call lands, after D67's fix

## Context

`D67` found and fixed a real gap: a real `generate()` candidate
defaulted its reference-corpus lookup to `.hotdocs/`, which
`SPEC_GUIDELINES.md` forbids any gate decision from depending on. The
fix — a new `VAR-LICENSE-CORPUS-PATH` — was made in spec, never
patched into the rejected candidate.

## Decision

A second retry, with that fix in place, produced a correct 587-line
candidate: reads the corpus path from the new var only, with no
`.hotdocs/` fallback anywhere; includes a resilient in-process
fallback `cache-manager` stand-in for a dependency it can't locate
(defensive, never exercised in practice since the real dependency is
always present). Verified against all 8 directly-testable
`AC-LICENSE-*` criteria for real (10 tests). Swapped in.

`AC-LICENSE-007` (an original flagged result must survive a later
clean retry) is not independently testable at this component's own
level — it depends on `provenance-writer`/`.hotdocs/attempts/`,
neither of which exist yet. Flagged, not silently skipped.

## Consequences

Eleventh real component built; batch 1 of the regen plan has three
components left (`secret-scanner`, `docs-site-renderer`,
`test-author`). `secret-scanner` shares `license-scanner`'s general
shape (`depends_on: [comp-cache-manager]`, a deterministic scan gate
with its own notification var) — watch for whether it hits the same
class of gap `license-scanner` just did, or a new one.

Linter: 0 failures once this file exists. Pytest: 140 tests across all
eleven real components, 10 of them this component's own.
