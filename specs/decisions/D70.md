# D70 — Glossary promotion criterion, and citation resolution for it

## Context

A convention needed by two or more components kept being discovered only reactively, after a real build failure, because nothing stated a positive rule for *when* to promote a shared fact to the glossary in the first place — only a consumption rule ("specs must use glossary terms as defined"). Separately, citations to glossary entries (quoting a bolded header) had become a real, consistent convention without any mechanical check that they actually resolve.

## Decision

A convention must be promoted to the glossary as soon as a second component states it, relies on it, or would need to independently guess it — the sibling discipline, for shared vocabulary and contracts, to the existing single-source-of-truth rule for computed facts. A glossary-term citation must mechanically resolve to a real entry, the same mechanism already used for other citation shapes in this corpus.

## Consequences

This closes only the citation-hygiene half of the gap; the actual promotion judgment call still depends on whoever is authoring or auditing a spec doing it.
