# D70 — First real call lands on the first try, after D69's pre-emptive fix

## Context

`D69` proactively declared `VAR-SECRET-PATTERNS-PATH` before any real
`generate()` attempt for this component, applying `D67`'s
`license-scanner` finding ahead of time rather than waiting to
rediscover it.

## Decision

The first real `generate()` call produced a correct 654-line
candidate on the first try: reads the pattern database path from
`VAR-SECRET-PATTERNS-PATH` only, implements both the full cache-aware
scan and `R-SECRET-008`'s lightweight `scan_files` precommit mode
(scoped files only, no `cache-manager` dependency), and redacts
matched excerpts rather than echoing full secret values into results
or logs — a careful touch nothing explicitly required but the spec's
own spirit (never persisting raw sensitive content) clearly implies.
Verified against all 10 directly-testable `AC-SECRET-*` criteria for
real (12 tests, including a brute-force-constructed entropy-threshold
test straddling 4.0 bits/char precisely). Swapped in.

`AC-SECRET-009` is not independently testable yet, same reason as
`license-scanner`'s `AC-LICENSE-007` — both depend on
`provenance-writer`, not yet built.

## Consequences

Twelfth real component built. Batch 1 has two components left:
`docs-site-renderer` and `test-author`. This closes out the
compliance-gate pair (`license-scanner`/`secret-scanner`) — both now
real, both found and fixed the same class of gap, one pre-emptively.

Linter: 0 failures once this file exists. Pytest: 152 tests across all
twelve real components, 12 of them this component's own.
