# D326 — A verifier test's helpers are never named test-anything

## Context

Regenerating `verifier-orchestrator` for the demo-build fixes, two
seeds' tests for `AC-VERIFY-019` defined a helper
`test_file_source(ac2_passes, ...)` that builds the sealed fixture's
characterization suite. Pytest collected it as a test, found no
fixture named `ac2_passes`, and errored, failing a criterion the
implementation met.

## Decision

`specs/architecture/verifier-fixtures.md`, which every
`verifier-orchestrator` criterion's test author sees, states that a
test's helper functions carry no `test` prefix, and that a fixture's own
test functions appear only inside string literals.

## Consequences

Only `verifier-orchestrator` implements that document, so only its
bundle changes. The rule applies to any test, but stating it in
`test-author`'s prompt would make three components regenerate again;
`notes/backlog.md` keeps that for later.
