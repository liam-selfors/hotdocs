# D26 — Scanner webhook delivery outcome is tracked separately from notification eligibility

## Decision

`LicenseScanResult`/`SecretScanResult` carry `notification_delivery_error` (`{category, message}` or `null`), distinct from `notified` (which only means a notification was due). The webhook call itself is a bounded, no-retry call, the same discipline every other real network call in this corpus follows.
