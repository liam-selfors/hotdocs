# D316 — The test-author prompt's fixed rules are exact text

## Context

Requirements `R-AUTHOR-010` to `R-AUTHOR-015` and `R-AUTHOR-021` to
`R-AUTHOR-024` described the prompt's fixed rules in paraphrase, and
their criteria paraphrased them again. Three seeds of a `test-author`
regeneration each failed a different one of them: a test asserting a
phrase the candidate worded otherwise, a test reading a word that the
candidate's worked example happened to use, and a test whose
`str.format` template held braces. Each seed passed every other
criterion with a mutation score of 1.0.

## Decision

The fixed rules move, as exact text, into
`specs/architecture/test-author-prompt.md`, one block per requirement,
with `@MODULE@` for the module under test. Each requirement says only
that the prompt holds its block; each criterion checks named lines of
the block exactly. Block `R-AUTHOR-024` also tells a test author to
build file sources by concatenation, never by formatting, the cause of
the third failure.

## Consequences

Neither the generator nor a test author words these rules, so a
criterion cannot fail on phrasing, and `test-author` loses about 350
words. A change to a rule is a change to the document, which every
`test-author` bundle includes.
