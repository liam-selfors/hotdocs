# D142 — R-PACKET-001's merge-base rule needed a same-branch fallback

## Context

Fifth and sixth `review-packet-builder` retries (two different seeds,
after `D141`'s two fixes): 10 of 11 pass both times, both times on the
identical remaining criterion, `AC-PACKET-007`, for two different
reasons across the two seeds.

The first (seed 0) was a test-authoring artifact: that attempt's fake
`provenance-tracker` recorded its own invocation in an in-process
module-level list, and the test asserted against that list through its
*own* earlier `importlib`-loaded reference to the fake module — but
`review-packet-builder`'s own loader (correctly, per `R-GEN-018`)
`exec_module`s a *fresh* module object on every call, which replaces
`sys.modules["provenance_tracker"]` without updating the test's
separate, now-stale reference to the module it loaded itself. Not
re-triggered at the next seed, so not invested in further for now —
flagged here in case it recurs.

The second (seed 1) is a real, now-confirmed gap in `R-PACKET-001`
itself (`D140`/`D141`'s own merge-base fix): that attempt's test
realized "a PR" as two commits directly on the current branch, with no
separate feature branch at all — the first time any round has done
this (`AC-PACKET-001`'s own passing test, round 3, used an actual
`feature` branch diverging from `main`). When `HEAD` and the repo's
default branch are the same ref (no divergence exists yet), `merge-base
HEAD <default>` resolves to `HEAD` itself, so `R-PACKET-001`'s diff
is `HEAD` against `HEAD` — empty, even though a real, committed change
(sealing `comp-foo`) obviously exists. `R-IMPACT-010`'s own convention,
borrowed wholesale, was built for a different situation (detecting
*uncommitted* working-tree drift from a ratified baseline, typically
invoked before a commit even exists) — not "show the diff for a PR
that has already been fully committed, possibly directly on the
default branch with no feature branch at all," which is at least as
common a shape for this component's own purpose.

## Decision

`R-PACKET-001` amended with the fallback round 1/2's own candidates
already had, independently, before `D140` removed it: when the
merge-base of `HEAD` and the default branch **is** `HEAD` itself (no
divergence), diff `HEAD~1` against `HEAD` instead — covering "two
commits directly on the current branch, no feature branch" as a
first-class case rather than silently returning an empty diff for a
change that demonstrably exists.

`review-packet-builder` is retried next.
