# D202 — The repository is licensed under Apache-2.0

## Context

The repository had no license file, so nobody outside it could legally
use, copy or contribute to the tool, and `pyproject.toml` declared none.
The MVP release is the first time anyone else is meant to install it.

## Decision

The repository is licensed under the Apache License, Version 2.0, in
`LICENSE` at the root and as `license` in `pyproject.toml`. Apache-2.0
over MIT because it adds an explicit patent grant from every
contributor, which matters for a tool whose generated code others will
ship, and it is the license `license-scanner` rates lowest in risk
(`R-LICENSE-003`, permissive).

## Consequences

Contributions are accepted under the same terms (section 5 of the
license). Generated code in a project belongs to that project; this
license covers the tool.
