# D352 — The tokenizer criterion for JavaScript in strings is retired with D335

## Context

`D342` pinned `D335`'s tokenizer for JavaScript held in Python strings
through a scenario of `AC-VERIFY-026`. `D343` replaced that mechanism
with declared asset kinds, and `AC-VERIFY-026` became the asset-strength
criterion, but `D343` could supersede only `D335`.

## Decision

`D342` is superseded: no criterion pins string-held JavaScript, since
the pipeline no longer mutates it. JavaScript is a declared
`javascript` asset, strength-checked by its adapter (`D343`).

## Consequences

`D342` is marked `deprecated`. Nothing is regenerated.
