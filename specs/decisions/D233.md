# D233 — `AC-ENDPOINT-004` gives its environment and values exactly

## Context

`AC-ENDPOINT-004` failed on three seeds of `llm-endpoint` in a row, each
time on its test's setup rather than the code: a `hotdocs.toml` from
elsewhere was visible, a credential the scenario said was set was not,
or the value given failed a different check first. The criterion
described its setup in prose ("a credential in the environment variable
a provider reads").

## Decision

`AC-ENDPOINT-004` names the environment (no config, an empty directory),
the exact key value and variables, the providers called, and the exact
`save_config` call and expected message.

## Consequences

`llm-endpoint` is regenerated.
