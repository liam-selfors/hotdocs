# D45 — component_id is always comp-&lt;slug&gt;; every gen/verification/specs path uses the bare slug

## Context

A real `generate()` candidate for `provenance-checker` built a path directly from a caller-supplied `component_id` without stripping its `comp-` prefix. This relationship was never documented anywhere — not in `SPEC_GUIDELINES.md`, not in a glossary — and every component that ever needed to resolve such a path had independently, silently reimplemented the same prefix-strip logic.

## Decision

Added a glossary entry stating the relationship explicitly: a component's id is always `comp-<slug>`, and every `gen/`/`verification/`/`specs/components/` path uses the bare slug. Reaches every future cold-mode `generate()` call automatically, since the glossary is part of every real `SpecBundle`.
