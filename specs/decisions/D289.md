# D289 — `docs-site-renderer`'s CLI, escaping and empty fields get criteria

## Context

Seeds 2, 3 and 4 of `docs-site-renderer` scored 0.34, 0.70 and 0.54 on
mutation. The survivors sat in code no criterion reached: the CLI's
exit codes, which `interface/cli.md` defined but no requirement cited,
HTML escaping, and fields that are null or empty.

## Decision

- `R-DOCS-007` requires the CLI's exit codes, and `AC-DOCS-007` covers
  them.
- `AC-DOCS-008` covers escaped document text and a node with null
  verification, provenance and owners.
- `interface/library.md` says every value written into a page is
  HTML-escaped.

## Consequences

`docs-site-renderer` is regenerated.
