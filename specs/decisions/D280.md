# D280 — Mutant runs ignore `conftest.py` files

## Context

Verifying a component in the real repo gave `mutation_score` 0.0 for
every component with a hand suite, from the previous
`verifier-orchestrator` and from its seed 8 candidate alike. The hand
suite's `verification/<slug>/conftest.py`, above the generated tests,
puts the real `gen/<slug>/` first on `sys.path` and imports the module,
so every mutant run tested the original code and every mutant survived.
Bootstrap sandboxes hold no hand suite, which hid it.

## Decision

`R-VERIFY-014` runs a mutant's tests with pytest's `--noconftest`.
`AC-VERIFY-022` covers a component whose conftest imports the original.

## Consequences

`verifier-orchestrator` is regenerated, and verifying in the real repo
measures mutation again.
