# D176 — graph-query-engine never exposed decisions, so R-LINT-028-030 were specced but unbuildable

## Context

Eight tests had been filed as "pre-existing": five for `spec-linter`'s
`R-LINT-028`–`030`, two for `graph-query-engine`, one for
`spec-bundle-assembler`. `D167` showed what that label hides, so each was
diagnosed on its own.

`R-LINT-029` and `030` are specced to query `nodes`/`edges` for decisions
(`D74`), and `graph-query-engine`'s `R-GQE-001`/`002`/`008` specify the
`decision` node kind, the `supersedes` and `builds_on` edges, and the
`decision_lineage` view. None of the three was ever in `views.sql`: the
two `graph-query-engine` failures and the two rules were one defect, and
the rules could not have been written against views that lacked their
subject.

## Decision

`views.sql` now implements the spec's SQL. Implementing it exposed three
further defects, each now fixed and guarded by a test:

- **A phantom edge.** The spec's SQL matched `supersedes:` anywhere in a
  decision's text. `D137` quotes `` `supersedes: [D17]` `` in prose, and the
  view reported a supersession no decision declares, which `R-LINT-029`
  would have raised. Anchoring to a line start was not enough, since a body
  line can begin with a field name, so the decision arms now extract the
  frontmatter block first and match fields only inside it (`R-GQE-002`,
  `R-GQE-008`). The edges now agree exactly with an independent
  frontmatter parse of every real decision.
- **A stale test.** `test_ac_gqe_009` asserted that `D31` supersedes `D17`
  in the real corpus. Commit `0fb1d53` renumbered every decision and reset
  the corpus to zero supersessions; the test kept asserting the old pair.
  It now builds a synthetic corpus. `AC-GQE-008` likewise described
  `decision_lineage` columns that `R-GQE-008` removed, and was rewritten.
- **A glossary-citation form the rule had to learn.** Real prose hard-wraps
  a citation across lines, puts a comma inside the closing quote, and
  contains the literal placeholder `"<Term>"` in `R-LINT-028`'s own text.
  The rule normalizes whitespace, drops one trailing `,.;:`, and ignores a
  quote that does not start alphanumerically. Without these it reported
  five false findings on the real corpus.

`R-LINT-028`–`030` are implemented as hard failures. The real corpus has no
violation of any of them. A rule that reports nothing proves nothing unless
it can fire, so a test copies the real corpus, injects one dangling
`builds_on`, one orphaned `deprecated`, and one `supersedes` of a ratified
decision, and expects exactly those findings.
