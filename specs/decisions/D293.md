# D293 — A `provenance-tracker` exception is a missing upstream result

## Context

Seed 2 of `review-packet-builder` failed `AC-PACKET-012`: a fake
`check_readiness` that raised escaped `main` instead of giving exit `1`.
`R-PACKET-012` gave exit `1` for "a required upstream result was
missing" without saying a tracker exception counts. The criterion also
named a `UsageError` that `provenance-tracker` does not define; it
raises `ValueError` (`D288`).

## Decision

`R-PACKET-012` counts any exception `check_readiness` raises as a
missing upstream result, exit `1` with its message. `AC-PACKET-012`'s
fake raises `ValueError`.

## Consequences

`review-packet-builder` is regenerated.
