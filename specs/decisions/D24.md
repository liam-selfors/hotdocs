# D24 — Cache-manager's concurrency safety doesn't require deterministic writers

## Decision

Last-write-wins under concurrent writes to the same key is safe because any write that survives a race is always an independently valid answer for that key — true regardless of whether the writer is deterministic. Nothing in this corpus requires every gate to produce byte-identical output across calls; only a cache *hit* must be.
