# D376 — The scenario verifier finds capabilities from component frontmatter

## Context

`R-SCENARIO-002` required the capability lookup to be "one query
against the shared `edges` view" and, in the same requirement, a scan
of every `component.md` "without `graph-query-engine` as a dependency".
`capability-scenario-verifier` does not depend on `graph-query-engine`,
so its generator got two instructions for one step; the committed code
scans frontmatter.

## Decision

The lookup reads the `realizes:` line of each
`specs/components/*/component.md` under `repo_root`. The capabilities
to run are the distinct ids named by the components in the blast
radius. The `edges` query is dropped.

## Consequences

One instruction, the one the code follows. Regenerated:
`capability-scenario-verifier` and the components its code hash
reaches.
