# D73 — Second real retry, a genuine interface gap this time

## Context

A second real `generate()` call for `test-author`, with `D72`'s
`gate_version` fix in place, produced a candidate that correctly used
`gate_type="generated_test"` — but implemented `author_test(bundle,
model, seed=0)` exactly as `interface/library.md` documented it, with
no way to inject a mock model at all. Every single `AC-AUTHOR-*`
criterion's own Gherkin requires "a mock model that records what it
was sent." `generator`'s own `interface/library.md` already documents
an `llm_backend` parameter for exactly this reason; `test-author`'s
never did. This candidate did exactly what its contract said — the
contract itself was incomplete, not the candidate.

## Decision

`interface/library.md` now documents `repo_root` and `llm_backend`
explicitly, mirroring `generator`'s own signature and parameter name
exactly — the same seam, not a second one. The candidate missing this
parameter was deleted before being committed, never swapped in.

## Consequences

A third retry, with this fix in place, is the next real test.

Linter: 0 failures once this file exists. Pytest: all 158 tests across
all thirteen real components re-verified unchanged (spec-only edit).
