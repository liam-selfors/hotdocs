# D243 — `ParsedCriterion.gherkin` holds the steps without their fence

## Context

Seed 20 of `criterion-compiler` emitted empty test bodies for every
criterion passed to `compile_criterion`: it looked for a
```` ```gherkin ```` fence inside `ParsedCriterion.gherkin`, as `D235`'s
description of an acceptance file suggested, but callers (and `compile`
itself) pass only the block's contents. The interface never said which.

## Decision

`interface/library.md` says `gherkin` holds the steps with the fence
lines removed, its first line being line 1; `D235`'s fence rule is how
`compile` finds them in a file.

Seed 21 then failed only `AC-COMPILE-012`, whose test looked for the
binding line without its indentation; the criterion now says "stripped of
its indentation".

## Consequences

`criterion-compiler` is regenerated.
