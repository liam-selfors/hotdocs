# D338 — The capability judge reads the first fenced block of a reply

## Context

`R-SCENARIO-008` said a reply "wrapped in" a Markdown code fence is
unwrapped first, and `AC-SCENARIO-011` asked for a reply "holding" the
JSON inside a fence. Test authors read that as prose followed by a
fenced block; generators unwrapped only a reply that starts with the
fence. `AC-SCENARIO-011` failed on three of four seeds of the
regeneration for issues #12 and #13, each time with a passing verdict
read as `judge unavailable`.

## Decision

The judge parses the lines between the reply's first line starting with
three backticks and the next such line, ignoring any prose around them,
or the whole stripped reply when no line starts with backticks.
`AC-SCENARIO-011` gives the exact reply text, prose on both sides of the
fence, and adds a bare JSON reply.

## Consequences

Only `capability-scenario-verifier` regenerates. A model reply with a
sentence before its fenced verdict now counts instead of failing the
scenario.
