# D238 — `llm-endpoint`'s `PROVIDERS` values are in its interface

## Context

Seed 12 of `llm-endpoint` failed two criteria. `AC-ENDPOINT-010`'s test
expected a provider's `suggested_model`, a value only the hand-written
code held: the interface named `PROVIDERS`' keys but none of its values.
And `AC-ENDPOINT-003` said "a rate-limit error", so a test raised a
class of its own, which `D224`'s classification rightly calls `network`.

## Decision

`interface/library.md` lists every provider's default base URL, key
variable and suggested model, as the hand-written version had them.
`AC-ENDPOINT-003` raises `HTTPError` 429. `component.md`'s Scope, which
restated the requirements, is shortened to make room.

## Consequences

`llm-endpoint` is regenerated.
