# D5 — spec_bundle_hash is permanently a function of raw bytes

## Decision

`spec_bundle_hash` hashes a spec bundle's raw bytes, permanently — Markdown is not whitespace-insensitive (trailing spaces are a hard-line-break; indentation is load-bearing), so no normalization rule is safe to hash against instead without risking two meaningfully different bundles hashing identically. The cosmetic-diff cache-hit-rate concern this raises is addressed at a different layer: `spec-linter` rejects trailing whitespace anywhere in a spec file as a fail-severity finding, keeping the problematic byte pattern from ever reaching a committed file.
