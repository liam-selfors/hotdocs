# D74 — Decisions are first-class nodes and edges in the corpus's shared query graph

## Context

Decision records were not part of the corpus's shared dependency graph at all. An initial attempt gave decision supersession its own, dedicated, parallel view instead of extending the graph's existing shared node/edge shapes — reasoned at the time as lower-risk, but re-examined, that reasoning didn't hold up: the existing node shape already fits a decision record exactly, with no new column needed at all.

## Decision

Decisions are a real node kind in the shared `nodes` view, and `supersedes`/`builds_on` are real edge types in the shared `edges` view — the same pattern every other kind of spec id already uses. The one fact with no equivalent column there (a decision's own ratification commit) keeps a small, dedicated view just for that.
