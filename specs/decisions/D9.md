# D9 — DuckDB (yaml + duckpgq extensions) is the corpus's local graph-query engine

## Decision

The corpus's dependency structure is queried via embedded, local DuckDB (no server, no network) with two community extensions: `yaml`'s `read_yaml_frontmatter()`, which queries frontmatter directly out of existing spec files with native glob support and needs no file restructuring; and `duckpgq`, providing SQL/PGQ graph-pattern matching for traversal (transitive reachability, cycle detection) rather than hand-rolled recursive CTEs.
