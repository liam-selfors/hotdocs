# D248 — `AC-CORPUS-003` checks that no README becomes a document

## Context

Seed 7 of `corpus-loader` passed every criterion at 0.84, but loading the
real corpus with it turned the `README.md` files of `specs/product/`,
`specs/architecture/`, `specs/vars/` and `specs/decisions/` into
documents, which `Corpus.md` excludes and the linter would then reject.
Only a component directory's `README.md` was tested.

## Decision

`AC-CORPUS-003` puts a `README.md` in each of those directories and
checks none becomes a `Doc`.

Seed 8 then kept each body's trailing newline again, so `Corpus.md` now
gives the expression that builds `body`.

## Consequences

`corpus-loader` is regenerated before the checkers.
