# D387 — Only a bare fenced block documents callables for the drift check

## Context

`R-VERIFY-004` said every callable an interface "documents" must exist,
without saying which text documents one. The verifier generated before
`D383` read only lines starting `name(` in the first column; the one
generated for `D383` also read indented lines and `def` lines in any
fenced block. `test-probe`'s interface shows, in ```` ```python ````
blocks, the stub module it writes, so its `def __init__(self, name)`
became a "documented callable" the module lacks, and every re-record of
`test-probe` failed on interface drift with all its criteria passing.

## Decision

A callable is documented by a first-column `name(` line inside a fenced
block with a bare opening fence. A block whose fence names a language is
an example. `GATE_VERSION` stays `verifier-orchestrator@4.0.0`: only
`test-probe`'s interface has language-tagged blocks, so no recorded
verdict changes and no other provenance key should miss.

## Consequences

`verifier-orchestrator` regenerates; its dependents re-verify their
committed code (`D379`), and `test-probe` re-records.
