# D295 — The decision-integrity scenario states the `supersedes` form

## Context

The corpus-wide `hotdocs verify` ran `CS-DECISION-INTEGRITY-001` and it
failed: its generated test wrote `supersedes: [D1]`, a list, which
`graph-query-engine` does not read, the mistake `D260` fixed in
`decision-drift-detector`'s own requirement. A capability scenario's
test author sees the scenario, not that requirement.

## Decision

`CS-DECISION-INTEGRITY-001` says the superseding decision's frontmatter
holds the scalar line `supersedes: <the earlier id>`, one id, never a
list. Product specs enter no component's bundle, so no component's
provenance changes.

## Consequences

The capability's gate is run again.
