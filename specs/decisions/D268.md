# D268 — The generator's reply format and module naming, stated exactly

## Context

Seed 1 of `generator` failed two criteria. Its prompt named the layout
with the literal placeholder `<slug_with_underscores>.py`, while
`AC-GEN-016`'s test looked for the real module name. And `AC-GEN-021`'s
test had to guess the reply's delimiter format from the prompt, because
no spec text gave it; the guess broke on a nested placeholder.

## Decision

`R-GEN-015` names the real module in the prompt, and states the reply
format: `-----BEGIN FILE <nonce>: <path>-----`, the content, then
`-----END FILE <nonce>-----`, with a fresh `uuid.uuid4().hex` nonce per
call, the same markers the hand-written generator used. To stay under
the word cap, `component.md`'s resolved open questions are removed and
its change log points to the decisions.

## Consequences

`generator` is regenerated.
