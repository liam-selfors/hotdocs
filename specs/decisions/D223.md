# D223 — `llm-endpoint`'s criteria state the environment they need

## Context

Seed 3 of `llm-endpoint` failed five criteria. Three were the candidate's
own defect: it read the reply's `getcode()`, which `D220` had excluded.
Two were the criteria's. `AC-ENDPOINT-001`'s test passed when run alone
and failed under verification, because the process it ran in had
`VAR_HOTDOCS_CONFIG` set, so "no hotdocs.toml" was not true; nothing told
the test to clear it. `AC-ENDPOINT-011` checked prefix stripping through
an injected backend, which by design bypasses resolution and receives the
identifier unchanged.

## Decision

`AC-ENDPOINT-001` starts from `VAR_HOTDOCS_CONFIG` unset and a fresh
directory, `interface/library.md` says resolution reads both, and
`AC-ENDPOINT-011` observes stripping in the recorded HTTP request.

## Consequences

`llm-endpoint` is regenerated against it.
