# D25 — A failed merge-tracker write is surfaced, never silently swallowed

## Decision

`MergeResult.tracking_write_error` (`{category, message}`, same shape as `model_call_error`) reports a failed tracking write visibly. Tracking itself stays best-effort and non-gating — a tracker failure never blocks a merge — but it is never silent.
