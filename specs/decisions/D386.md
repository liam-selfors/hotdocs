# D386 — One generated stylesheet, a css asset kind, and computed styles in the browser driver

## Context

`docs-site-renderer` and `provenance-tracker-ui` each wrote their own
CSS, chosen afresh on every generation: `R-DOCS-002` asked only that
size be "color-coded", `R-UI-002` that each status have "a visually
distinct style". No criterion could check a colour, contrast or dark
mode, because the browser driver read no style and the pipeline had no
asset kind for a stylesheet.

## Decision

- **Rules.** `specs/architecture/visual-style.md` names the tokens,
  the contrast pairs and thresholds (WCAG 2.2: 4.5 for text, 3 for
  non-text), the four tone classes and how each status maps to one,
  and what a page may and may not do with CSS. Each page implements it.
- **Values.** The new component `comp-ui-style` holds them once, in a
  declared `css:static/style.css` asset with light and dark tokens,
  base rules and tone classes, and a `style_element()` each page
  inlines. The pages depend on it, so a new colour regenerates
  `comp-ui-style` alone and re-verifies the pages (`D379`).
- **Kind.** The new kind `css` (`specs/architecture/asset-kind-css.md`,
  adapter `comp-kind-css`) checks a plain stylesheet in Python: layout,
  tokens and classes as surface, `asset_runner` entries for tokens,
  rules and contrast, and declaration deletion as its mutation.
  Following `D343`'s lookup, no pipeline component changes;
  `asset-kinds.md`'s table of built-in kinds gains the row with the
  next change to that document.
- **Driver.** The browser driver gains `Element.style(property)`, a
  computed value, and `open(..., color_scheme=...)`. Page criteria
  compare computed values with each other and with the thresholds,
  never with a token's literal value. Pixels and screenshots stay for
  people (`D373`).

## Consequences

New: `comp-kind-css`, `comp-ui-style`. Regenerated: `comp-driver-browser`,
`docs-site-renderer`, `provenance-tracker-ui`. No pipeline component's
bundle changes. Not done here: screenshots in the review packet, which
needs `run-environment` to keep them and so regenerates the verifier
stack, and moving the DAG's edge colours to tokens (`visual-style.md`,
open questions).
