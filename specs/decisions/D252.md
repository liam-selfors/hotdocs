# D252 — The generation prompt asks for no behavior beyond the spec

## Context

The first generations on Opus (`D250`) passed every criterion of
`cache-manager` and `llm-endpoint` but reached mutation scores of 0.70
and 0.68. The surviving mutants sat in validation and fallback branches
no requirement asked for, which no criterion could reach.

## Decision

`R-GEN-020` requires the prompt to ask for exactly the specified behavior
and nothing more, saying why. The hand-written `generator` in use gets
the same rule now, with its prompt and gate versions bumped so no cached
result from the old prompt is reused.

## Consequences

Generated code stays within what its criteria test.
