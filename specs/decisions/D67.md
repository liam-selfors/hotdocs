# D67 — A provenance manifest's computed/derived fields each need a stated source

## Context

Three manifest fields appeared in a bundle-visible schema example with no requirement stating where any of them should come from — one of them via a cross-reference that, checked against the real code it named, turned out to be false. A claimed source is not evidence the source actually exists.

## Decision

Each field now has an explicit, real source: one is sourced from the one upstream component capable of supplying it (added there directly, since no existing dependency could); one is a component-owned version constant; one is a deterministic construction from already-available input fields, consistent with the component's own determinism requirement (a freshly generated random value would have violated it).
