# D391 — Re-seal the secret allowlist after the D390 regeneration

## Context

The `D390` regeneration re-authored `driver-browser`'s tests. One of them,
`verification/driver-browser/generated-test/test_ac_drv_010.py`, holds the
hex bytes of a one-pixel PNG image it serves to the browser, which the
scanner reads as a high-entropy string. The value is not quoted here, so
this record is not itself a finding.

## Decision

The allowlist is the scanner's own `propose()` output, the new line read
by hand: the 50 entries sealed by `D388` plus that one, `planted-fixture`;
`propose()` reported nothing ineligible. This record carries the file's
hash.

## Consequences

A full scan is clean again.
