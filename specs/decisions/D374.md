# D374 — test-author's bundles carry the test-reuse rules

## Context

`R-AUTHOR-028` and `R-AUTHOR-030` depend on
`specs/architecture/test-reuse.md`: its criterion header and its wording
for a reused test. `test-author`'s `interface/library.md` named the
document in prose but not on its `Implements:` line, so
`spec-bundle-assembler` appended it to neither the generator's bundle
nor any criterion's (`R-ASSEMBLE-014`). Both requirements were written
against text no model saw. The spec review of 2026-11-26 found it.

## Decision

`test-author`'s `Implements:` line names `specs/architecture/test-reuse.md`.
Its stale constraint that it handles credentials, contradicted by
`R-AUTHOR-008` since `D18`, is removed.

## Consequences

`test-author`'s generator and every one of its criterion tests now see
the header format and reuse rules they implement. Regenerated:
`test-author`, and the components its code hash reaches.
