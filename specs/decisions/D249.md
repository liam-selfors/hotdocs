# D249 — `R-COMPILE-013` names the grammar's construction step, which binds a snake_case name

## Context

Five generations of `criterion-compiler` in a row rejected
`Given a Thing with name: "a", size: 2`, the grammar's own construction
template, and accepted `Given a <name> is a <Type> with ...` instead.
`R-COMPILE-013` described the step as `Given a <fixture> is a <Type>`,
a form the grammar never had, and every candidate followed the
requirement. The grammar also never said what name a constructed value is
bound to; the hand-written compiler used the type's snake_case name.

## Decision

`R-COMPILE-013` refers to `Given a <Type> with ...`, and the grammar says
it binds the snake_case name and that the `is a <Type>` form does not
exist.

## Consequences

`criterion-compiler` is regenerated.
