# D286 — The corpus graph carries owners and documents for the docs site

## Context

`R-DOCS-002` has a component's detail view show its rendered spec
content and owners, and `R-DOCS-004` makes the site a pure function of
`corpus-graph.json`; but `CorpusGraph`'s component nodes carried
neither. Seed 2 of `docs-site-renderer` failed `AC-DOCS-002` on a test
that invented node fields for them, and the previous renderer had
guessed at keys the graph never wrote.

## Decision

- `R-GRAPH-003` and `CorpusGraph.md`: a component node also carries
  `owners`, the frontmatter list, and `documents`, every `.md` file
  under the component's directory by relative path; `AC-GRAPH-011`
  covers them.
- `docs-site-renderer`'s `interface/library.md` names the node field
  behind each part of the detail view, and `AC-DOCS-002` sets each of
  those fields.

## Consequences

`corpus-graph-builder` is regenerated, then `docs-site-renderer`.
