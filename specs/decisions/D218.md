# D218 — Every loader accepts a component as a flat module or a package

## Context

`R-GEN-014` already lets a generated component be a flat module or a
package, and the regenerated `cache-manager` and `spec-bundle-assembler`
are packages. Three loaders only knew the flat shape. The hand-written
`generator` crashed on the next run of every bootstrap, `hotdocs-cli`
loads each verb's module as `<module>.py` (so `hotdocs assemble` broke),
and `hotdocs-init` loads `llm_endpoint.py`. Each component's own
generated tests could not catch this: the failure is in a consumer.

## Decision

`generator`'s loader, hand-written, now falls back to
`<module>/__init__.py`. `R-CLI-001` and `hotdocs-init`'s
`interface/library.md` say the same, and both are regenerated.

## Consequences

Until `hotdocs-cli` is regenerated, a verb whose module is a package
fails to load. The final check runs every verb from a project.
