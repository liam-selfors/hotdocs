# D4 — criterion-compiler emits a single fixed target for v1, with parse/bind kept separate from emit

## Decision

`criterion-compiler` targets exactly one test framework (`pytest`) for v1 — no multi-target machinery built for frameworks nothing asks for yet. The step-phrase grammar is written in target-independent terms (each template's "compiles to" column describes a bound fact, never literal syntax), and the parse/bind phase (grammar matching, `interface/` resolution) is formally separate from the emit phase (literal source text for one target). Any other `--target` fails as a specific usage error, never a silent fallback.

## Consequences

A future second target is an additive emitter, not a grammar rework.
