# D38 — generator's prompt embeds a per-call nonce to avoid self-referential delimiter collisions

## Context

`generator` is the one component whose own generated source legitimately needs to contain a literal instance of its own file-transfer delimiter. A real retry's model response reproduced a worked example of the delimiter inside its own regenerated prompt string, and the old parsing regex matched that inner, illustrative end-marker first, truncating the real file.

## Decision

A fresh `uuid4().hex` nonce per `generate()` call, embedded in both the prompt's BEGIN/END FILE markers and the per-call-compiled parsing regex. The model is told to describe the delimiter format in prose rather than reproduce the literal token sequence if it needs to document this format inside its own generated code.
