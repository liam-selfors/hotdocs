# D250 — Components are generated with Claude Opus

## Context

Every component but one pinned `model_pin: claude-sonnet-5`, and the
regeneration of the tool's own components ran on that model. The
maintainer asked for generation to move to Opus.

## Decision

Every component's `model_pin` is `claude-opus-5-5`, and the tool's own
components are generated with it. The bootstrap's build configuration
names the same model and runs every model call at high effort.

## Consequences

`model_pin` is part of each `component.md`, so every bundle hash changes
and every component is regenerated, including the four already landed
with Sonnet; their manifests become stale until then. The model a user
project generates with is unchanged: `hotdocs init` still suggests the
provider's own default.
