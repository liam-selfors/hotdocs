# D257 — Four `llm-endpoint` behaviors the hand suite checks, now in the spec

## Context

Seed 25 of `llm-endpoint` passed every criterion, and four of the
hand-maintained suite's tests failed. Each checked behavior the hand
version had and no spec text required: a missing-key message naming the
variable, a `gemini` model given as `models/<name>`, a `base_url` that
is not an HTTP URL, and `check_connection`'s token budget.

## Decision

- `R-ENDPOINT-005`: the missing-key `auth` message names the variable.
  A variable's name is not a secret.
- `R-ENDPOINT-007`: `base_url` is an `http` or `https` URL.
- `R-ENDPOINT-008`: a `gemini` model written `models/<name>` is sent as
  `<name>`.
- `interface/library.md`: `check_connection` sends `max_tokens=1024`
  except to `claude-cli`, enough for a model that reasons before
  answering.

## Consequences

`llm-endpoint` is regenerated.
