# D31 — A file's named-section pointer must mechanically resolve to a real heading

## Context

A cross-reference naming a specific section of another file (rather than the file as a whole) goes stale silently when either side changes — the file moves, or the section it names gets renamed — with nothing to catch it.

## Decision

Every such pointer in a live document must resolve: the named file must exist, and must contain a heading matching the named section exactly. Mechanically checked, the same way other cross-reference shapes in this corpus are.
