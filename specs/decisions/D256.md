# D256 — `AC-SIZE-001` names the dimension by its key

## Context

`AC-SIZE-001` asked for a finding "citing the 'Generated code per
component' dimension", the human name in `SPEC_GUIDELINES.md` §4, while
`R-SIZE-001` names each dimension by its key. Seed 1 of `size-checker`
reported `generated_code_loc`, as the hand tests expect, and the
generated test, searching for the human name, failed it.

## Decision

`AC-SIZE-001` asks that the finding's message name `generated_code_loc`.

## Consequences

`size-checker` is regenerated. Each criterion now names a dimension
the same way its requirement does.
