# D18 — llm-endpoint is the one vendor-agnostic transport for every model call in the pipeline

## Decision

Every model call in the pipeline goes through one component: `complete(prompt, model, **params) -> ModelResponse`. It resolves a model identifier to a backend internally — callers never name or configure a backend, only a model; an unresolvable identifier fails immediately, never a silent fallback. Ships exactly one backend (Anthropic) — no multi-vendor machinery built for vendors nothing calls yet. No retry-with-backoff of its own. The credential never reaches any caller. Prompt construction and response parsing for any specific task stay with each caller — this component only knows "send this text to this model."

## Consequences

A future non-Anthropic backend must provide its own bounded-call guarantee if its runtime doesn't natively supply one.
