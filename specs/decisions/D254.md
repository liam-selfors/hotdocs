# D254 — `CompileReport` reads `GATE_VERSION` when it is built

## Context

Seed 25 of `criterion-compiler` failed only `AC-COMPILE-010`, whose test,
like the hand-maintained characterization suite, simulates a grammar
change by replacing the module's `GATE_VERSION`. The candidate had
captured the value at import. The interface said the constant is the
report's `gate_version` without saying when it is read.

## Decision

`interface/library.md` says the report reads it when built, and
`AC-COMPILE-010` describes the replacement exactly.

## Consequences

`criterion-compiler` is regenerated.
