# D279 — `verifier-orchestrator`'s bundle carries the step-phrase grammar

## Context

Seed 7 of `verifier-orchestrator` failed `AC-VERIFY-013` and
`AC-VERIFY-014` on tests whose fixture criteria were `compiled` but
written in steps the grammar does not recognize, so they never
compiled; one test tried six guessed phrasings. A criterion's test
author never saw `specs/architecture/step-phrase-grammar.md`.

## Decision

`interface/library.md` adds `Implements:
specs/architecture/step-phrase-grammar.md` (`R-ASSEMBLE-014`), so the
grammar enters the bundle and every criterion's test author sees it.

## Consequences

`verifier-orchestrator` is regenerated.
