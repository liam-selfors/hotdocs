# D116 — spec-linter's own interface doc understated lint()'s real signature

## Context

The `spec-bundle-assembler` retry exercising `D115`'s frontmatter fix regressed on three criteria whose synthetic-fixture tests use `R-AUTHOR-015`'s own self-check (`spec_linter.lint()` against the fixture before trusting it) for the first time in a way that actually calls it with the documented signature. All three failed identically: `TypeError: lint() missing 1 required positional argument`. Diagnosis: `specs/components/spec-linter/interface/library.md` documents `lint(paths: list[Path], repo_root: Path, strict: bool = False) -> LintReport`, but the real, already-shipped implementation is `lint(paths: list[Path] | None, repo_root: Path, strict: bool = False, judge=None) -> LintReport` — accepting `None` for `paths` (meaning "lint everything") and a `judge` callable neither of which the doc ever mentioned. `paths` documented as a bare, non-optional `list[Path]` gave the model no way to know `None` was valid, let alone the real calling convention every one of this session's own diagnostic scripts has used throughout (`lint(None, repo_root=...)`). This is a pre-existing documentation gap, not introduced this session, that only surfaced once a real self-check actually called `lint()` with real-world calling conventions for the first time.

## Decision

`specs/components/spec-linter/interface/library.md` is corrected to the real signature, with a one-line note on what `paths=None` and `judge` mean. Pure documentation fix — `spec-linter`'s own code is already correct and needs no regeneration. `spec-bundle-assembler` is retried once more.

**Noted, not acted on**: fixing this pushed `spec-linter`'s own `component_doc_words` to exactly the 4000-word hard-fail boundary — confirming `R-LINT-022`'s own standing warning that this component already crowds four size-cap dimensions at once (`acceptance_count`, `component_doc_words`, `generated_code_loc`, `requirement_count`), a decomposition signal per `SPEC_GUIDELINES.md` §4. Out of scope to act on here; recorded so the next person touching `spec-linter`'s docs knows there is no slack left.
