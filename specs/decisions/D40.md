# D40 — cache-manager's per-gate-type required payload keys are documented in interface/data/CachedResult.md

## Context

A real cache write for `generator` raised a schema-validation error for missing required keys — `cache-manager`'s own required-keys table was real and enforced but never documented in any spec file a dependent could see. A first attempt documented it in a requirement file; checking the bundle-assembly boundary found a dependent's bundle never includes a dependency's `requirements/`, only its `interface/` — making that first fix real but invisible to the exact scenario it was meant to fix.

## Decision

The schema table lives in `interface/data/CachedResult.md` — the one location a dependent's bundle actually surfaces. The corresponding requirement points to it rather than repeating it.
