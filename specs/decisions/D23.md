# D23 — Capability scenario results are per-scenario, with structured rationale

## Context

A capability with multiple scenarios needs to show which one failed, not one aggregate verdict; an `llm-judge`-kind scenario's failure needs the same structured-rationale treatment every other judgment-based result in the corpus gets.

## Decision

`CapabilityScenarioReport` reports one entry per scenario (`{id, kind, result, rationale?}`), with an `overall` field aggregating them the same way `VerificationReport.overall` does (a skipped `llm-judge` scenario alone doesn't fail `overall`). `rationale` is present only for `llm-judge`-kind scenarios that actually ran.
