# D251 — `AC-GQE-001`'s count excludes README files

## Context

Seed 12 of `graph-query-engine` failed only `AC-GQE-001`: its test counted
the `README.md` in `specs/product/`, `specs/vars/` and `specs/decisions/`
as nodes, which no view (and no other component, `D248`) treats as a spec
document.

## Decision

`AC-GQE-001` says its independent count never includes a `README.md`.

## Consequences

`graph-query-engine` is regenerated.
