# D64 — generator suppresses gen/ and cache writes in hint mode

## Context

`generator`'s real `generate()` only used `bundle.hint_code` to add it to the model prompt, never to gate whether it wrote to `gen/<component>/` or to the cache — identical behavior in `hint` and `cold` mode. This is not just destructive to a non-destructive preview's whole purpose: `spec_bundle_hash` deliberately excludes `hint_code`, so a `hint`- and `cold`-mode call for the same spec state compute the *same* cache key — an unsuppressed `hint`-mode write could let a later `cold` build silently reuse a candidate the model produced while looking at prior code, breaking the cold-build invariant itself.

## Decision

In `hint` mode, `generate()` returns the candidate (or cache hit) in the result only, writing to neither `gen/<component>/` nor the cache. Reading the cache stays enabled in `hint` mode — a hit can only exist for a hash already matching some committed, canonical state, so reuse is safe.
