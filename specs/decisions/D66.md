# D66 — A merge block decision must name the exact field it reads from each scanner

## Context

Two scanners' own "blocking" result field have two different names across their schemas. A block-decision rule describing this as "either scanner reported a blocking flag" named neither field explicitly, risking a wrong or missed field check by whoever implements the aggregation.

## Decision

The block-decision rule now names both exact fields explicitly, rather than describing the concept generically.
