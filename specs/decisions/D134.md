# D134 — decision-drift-detector's citation regex and dependency resolution were both wrong

Second real cold-generation attempt (after `D133`'s `kind:
generated-test` fix): `mutation_score=1.0`, all three criteria still
failed, for two distinct, precisely diagnosed causes.

**`AC-DRIFT-001`** — `assert len(entries) == 1` got `0`. The
candidate's citation regex required backtick-wrapping
(`` `(D\d+)` ``); the generated test's fixture cited `D17` in bare
prose ("MUST behave per decision D17"), a legitimate citation under
`spec-linter`'s own real rule (`R-LINT-026` uses `\bD\d+\b`,
backtick-agnostic). `R-DRIFT-001` had only said "the same citation
shape `R-LINT-026` already validates" in the abstract, which the
candidate implemented too narrowly — the same "worked snippet beats
prose" lesson recurring from `R-AUTHOR-010`/`R-TRACK-010`. `R-DRIFT-001`
amended with the literal pattern.

**`AC-DRIFT-002`/`AC-DRIFT-003`** — both failed because the fake
`graph-query-engine` module the test wrote under its own
`repo_root/gen/graph-query-engine/` was never actually loaded.
Diagnosed directly: `_load_graph_query_engine()` derived the
dependency's path from `Path(__file__).resolve().parents[2]` — this
component's own on-disk location — never from the `repo_root`
parameter `find_decision_drift`/`find_decision_impact` actually
received. Inside this driver's own sandboxed verification, that
`__file__`-relative path happens to also contain a real copy of
`graph-query-engine` (copied there as this component's own
dependency), so the candidate silently loaded the *real* module
instead of the test's fake and never called it — surfacing as a
behavioral assertion failure (`load_calls` file never written, `[]`
instead of `['D2']`) rather than an obvious crash. The identical bug
class `R-TRACK-011`/`R-VERIFY-013` already closed twice this session,
for `provenance-tracker` and `verifier-orchestrator`'s own loaders.
New `R-DRIFT-004` states it a third time, now with a literal worked
snippet for this exact candidate.

Retrying generation next.
