# D48 — "The prior commit" resolves to the merge-base between HEAD and the repository's default branch

## Context

A real candidate for `impact-analyzer` implemented no git comparison at all, because "the prior commit" — required by its own interface-change-detection text — was never defined anywhere in the corpus, and every real caller only ever supplies component-level ids, never anything finer-grained to infer a git ref from.

## Decision

"The prior commit" is the merge-base between `HEAD` and the default branch — the commit the branch actually diverged from, not `HEAD~1` and not the default branch's current tip. Per-file change detection must be a real git content comparison against that commit, never inferred from an id's shape. `BlastRadiusReport` uses the `comp-<slug>` format consistently.
