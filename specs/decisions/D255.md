# D255 — `save_config` creates its directory and replaces only the `[llm]` table

## Context

Seed 24 of `llm-endpoint` failed only `AC-ENDPOINT-013`, which expects
`save_config` to create a missing directory, as the hand-written version
did. No requirement said so, and under `D252`'s rule against behavior
beyond the spec the candidate rightly left it out.

## Decision

`interface/library.md` says `save_config` creates the directory when
missing and replaces only the `[llm]` table, the second already covered
by `AC-ENDPOINT-007`.

## Consequences

`llm-endpoint` is regenerated. `D252` makes such gaps visible: behavior
a criterion expects must now be written in the spec.
