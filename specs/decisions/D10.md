# D10 — merge-tracker/merge-tracker-ui give durable, queryable, local visibility into every merge attempt

## Decision

`merge-tracker` writes one record per merge attempt (success or block) to a gitignored, non-gating local store, queryable via DuckDB's `read_json` — no bespoke query API. It depends only on `provenance-writer`, never `merge-orchestrator`, specifically to avoid a dependency cycle. `merge-tracker-ui` renders this client-side. This pair exists so a partially-failed merge's status is visible and recoverable per component, without a developer needing to have kept raw CLI output.
