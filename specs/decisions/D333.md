# D333 — graph-query-engine's criteria use a stated fixture corpus

## Context

`AC-GQE-001`, `002`, `003` and `006` checked the views against "a real
spec corpus", and their tests read the repository's own `specs/`. Under
`D324` a mutation run copies only `gen/`, so four of five seeds of
`graph-query-engine` failed the mutation baseline, and the fifth failed
`AC-GQE-006` on an independent word count that disagreed with the view
by one. The tests main had committed built their own corpora; freshly
authored ones did not.

## Decision

`specs/architecture/graph-query-engine-fixture.md`, which the component
implements, states one synthetic corpus file by file and what each view
returns for it, checked against the current code. The four criteria
name that corpus and its exact results.

## Consequences

`graph-query-engine`'s interface changes, so its dependents' bundles
change too; every component regenerates in this wave anyway.
