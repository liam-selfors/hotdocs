# D56 — test-author's gate_version prefix must be exactly "generated_test," not the component's own name

## Context

A real candidate set its gate-version prefix to its own component name, reasonably mirroring another component's pattern where the component name and artifact kind happen to coincide — but `cache-manager`'s gate-type registry has no entry for the component's own name; the real entry for this artifact kind is `generated_test`. Confirmed by a direct cache-write failure.

## Decision

Clarified directly: the prefix must be exactly `generated_test`.
