# D65 — Injected judge/test_author callable contract

## Context

The single-`bundle`-argument shape two real components independently call `judge`/`test_author` with existed only inside one of their own `gen/` source files — never stated anywhere a third, dependent component's bundle would see it. The one existing cross-reference claiming a shared pattern with an unrelated component's own `judge` parameter was checked against that component's real code and found to be simply false.

## Decision

The real, confirmed contract — `judge(bundle) -> outcome` / `test_author(bundle) -> outcome`, duck-typed outcome handling — is now a named glossary entry. `bundle` itself is not one universal shape: a component with a natural, already-specified bundle for a single unit reuses it rather than inventing a second one; a component operating cross-unit (no single bundle applies) states its own narrower, purpose-built shape instead. Neither of the two real functions these closures ultimately wrap matches the single-argument shape themselves — whoever constructs the closure must capture the other parameters itself, stated explicitly since nothing upstream assigns that responsibility otherwise.
