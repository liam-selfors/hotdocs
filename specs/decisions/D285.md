# D285 — `docs-site-renderer` is a package with `cli.py`

## Context

`hotdocs-cli` runs `docs_site_renderer.cli`'s `main`, but
`docs-site-renderer`'s interface, unlike `corpus-graph-builder`'s, never
said so. Seed 1 generated a flat module, which the consumer-surface gate
refused.

## Decision

`interface/library.md` says it is a package, `__init__.py` plus
`cli.py`, whose `cli.main(argv)` takes the tokens from `build` on, in
the words `corpus-graph-builder`'s interface already uses.

## Consequences

`docs-site-renderer` is regenerated.
