# D253 — `AC-GQE-001` excludes only the README files the corpus has

## Context

`D251` told `AC-GQE-001` never to count a `README.md`. Seed 13's test then
planted one inside a component's `acceptance/`, which `R-GQE-001`'s own
SQL counts, since no component directory holds one.

## Decision

`AC-GQE-001` names the three READMEs it excludes and says no other
directory holds one.

## Consequences

`graph-query-engine` is regenerated.
