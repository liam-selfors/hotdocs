# D348 — A component CLI's main takes only argv; an injectable form is run

## Context

`specs/architecture/cli-conventions.md` gives every component CLI the
entry `main(argv: list[str] | None = None) -> int`, and the regenerated
`verifier-orchestrator` checks it as interface drift. `hotdocs-init` and
`hotdocs-cli` documented `main` with keyword parameters (`tool_root`,
`input_fn`, `cwd` and others) for tests and for the entry point, so no
implementation of either could pass.

## Decision

Each keeps those keywords on `run(argv, *, tool_root, ...)`, with the
same behaviour `main` had, and `main(argv)` calls `run` with the tool
root found as the parent of the nearest directory named `gen` above the
module's own file. `hotdocs-cli` calls `hotdocs-init`'s `run`, and
`tools/hotdocs_entry.py` calls `hotdocs-cli`'s `run` (falling back to
`main` for an older build).

## Consequences

`hotdocs-init` regenerates before `hotdocs-cli`, which calls its `run`.
