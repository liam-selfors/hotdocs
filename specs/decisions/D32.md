# D32 — VAR-ANTHROPIC-API-KEY resolves via a direct ANTHROPIC_API_KEY environment lookup

## Decision

A plain process-environment lookup of `ANTHROPIC_API_KEY` — the same variable the Anthropic SDK and `claude` CLI already read by default. No vault/secrets-manager indirection. If set, it always outranks a separate Pro/Max plan login for billing purposes in the same environment — a fact about real infrastructure a caller must confirm for themselves, not something this corpus can assert on their behalf.
