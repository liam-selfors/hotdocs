# D377 — The provenance manifest is defined by provenance-writer's interface

## Context

`R-PROV-001` and `R-PROV-011` required the manifest to hold exactly the
fields of `SPEC_GUIDELINES.md` §7, "the single source of truth", and
`interface/data/provenancemanifest.md` called itself a copy "not a
second definition". `provenance-writer`'s bundle never includes
`SPEC_GUIDELINES.md`, so its generator worked from the copy while
being told the copy did not count. The two agree today.

## Decision

`interface/data/provenancemanifest.md` defines the manifest's
top-level fields; `R-PROV-001` and `R-PROV-011` cite it.
`SPEC_GUIDELINES.md` §7 becomes a summary for spec authors pointing to
it when the guide is next edited. `R-PROV-014` names `write_provenance`,
not a `build_manifest` the interface never declared.

## Consequences

The definition the generator follows is the one it is told to follow.
Regenerated: `provenance-writer` and the components its code hash
reaches.
