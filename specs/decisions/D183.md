# D183 — llm-endpoint owns the provider list that hotdocs init presents

## Decision

`hotdocs init` helps a user pick and verify a provider, and it must not
keep its own copy of the provider list (`SPEC_GUIDELINES.md` section 10).
`llm-endpoint` therefore exports `PROVIDERS`, `load_config`,
`save_config`, `detect_providers`, and `check_connection`
(`R-ENDPOINT-009`). `detect_providers` reads only the `env` it is given,
so a caller or test needs no real environment; `claude-cli` counts as
available when `claude` is on `PATH`, a key provider when its variable is
non-blank, and `ollama` when its server answers within about a second.
`openai-compatible` is never auto-detected, since it cannot be guessed.
`check_connection` makes one real completion with a 1024-token budget (a
smaller one can be spent entirely on a reasoning model's hidden thinking
and report a working provider as broken) and returns `{ok, error}`.
