# D365 — hotdocs init ignores dist/

## Context

`hotdocs docs-site build` writes the site to `dist/` by default. The
`.gitignore` `hotdocs init` writes did not list it, so a new project's
first `git status` after building the site showed generated pages.

## Decision

`R-INIT-001`'s `.gitignore` lines gain `/dist/`.

## Consequences

`hotdocs-init`, a leaf, is regenerated. An existing project gains the
line on its next `hotdocs init`, which adds only what is missing.
