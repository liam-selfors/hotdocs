# D17 — spec-linter checks per-file word counts and per-file-type element counts, not only whole-bundle aggregates

## Decision

Beyond the whole-bundle word-count aggregate, `spec-linter` separately flags any individual `requirements/`/`acceptance/` file running long (a signal a bundle-wide aggregate can't distinguish from "lots of ordinary content spread evenly"), and separately caps the count of guarantee files and acceptance-criteria files per component. All thresholds are a first pass, explicitly open to recalibration as more of the corpus exists to test them against.
