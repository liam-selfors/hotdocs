# D177 — AC-ASSEMBLE-011's long-recorded cause was wrong; the generated test built a file with no frontmatter

## Context

`spec-bundle-assembler` landed at 14 of 15 with `AC-ASSEMBLE-011` failing,
recorded in `D118` as `graph-query-engine` mishandling a corpus with zero
decision files, "not chased here". That explanation was never checked. It
was also wrong: at that point `views.sql` read no decisions at all.

Reproducing the failure shows the real cause. The generated test builds
each synthetic `component.md` with `textwrap.dedent` over an f-string that
interpolates a multi-line value. The interpolated lines carry no
indentation, so `dedent` finds a common margin of zero and leaves the
surrounding eight-space indent in place. The file then does not begin with
`---`, has no frontmatter, `read_yaml_frontmatter` returns no rows, and
`lint()` fails binding `id`. Neither `graph-query-engine` nor the assembler
was at fault.

## Decision

`AC-ASSEMBLE-011` now states exactly what its synthetic corpus must look
like to pass `spec-linter`: sealed components with a `source_path`, an
uppercase `MUST` in each requirement, a `Kind:` tag in each acceptance
file, and every frontmatter file starting `---` in column 0.

**This did not make the test pass, and the criterion is not fixed.** A
full regeneration of `spec-bundle-assembler` (seed 11) failed 14 of 15
criteria, because the freshly authored tests did `from spec_linter import
lint`, a static import of a dependency that `R-AUTHOR-010` says is never
importable. Authoring `AC-ASSEMBLE-011`'s test alone, four times against
the new wording (seeds 41-44), produced two collection errors from that
same static import and two assertion failures. Nothing was swapped in:
the landed code and tests are unchanged, and `AC-ASSEMBLE-011` still
fails on its original `dedent` fixture defect.

What is left is a `test-author` weakness, not an assembler one, and
`test-author`'s spec is at its word cap: it needs a rule that a test never
imports a dependency by name, and one against `textwrap.dedent` over
interpolated multi-line values. Until then the failure is recorded here
with its true cause rather than as a limitation of `graph-query-engine`.
