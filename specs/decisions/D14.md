# D14 — capability-scenario-verifier is a separate component from merge-orchestrator

## Context

Capability-scenario dispatch originally lived inside `merge-orchestrator` only because an earlier decision added it to an existing sequencing step, not because it conceptually belonged there.

## Decision

Capability-scenario verification (dispatch against the real assembled system, once every blast-radius component has passed per-component verification) is its own component, structurally the cross-component analog of what `verifier-orchestrator` already does per-component. `merge-orchestrator` only owns *when* and *with what* it's called, not the dispatch mechanics.
