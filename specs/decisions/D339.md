# D339 — Verifier tests supply the compiler in repo_root

## Context

`verify` loads the sealed criterion compiler from
`<repo_root>/pipeline/criterion-compiler/`, else from the tool root
(`D199`). Tests re-authored for issues #12 and #13 left the compiler out
of their fixture and passed in the criterion run through that fallback.
A mutation run's tool root holds only `gen/` (`D324`), so two of five
seeds failed the mutation baseline with the compiler missing, the same
gap `D336` closed for `capability-scenario-verifier`.

The other three seeds were stopped by `tools/bootstrap_component.py`'s
dependency-surface gate, which read `assembler.append(...)` on a local
list named `assembler` as a use of `spec-bundle-assembler`.

## Decision

`specs/architecture/verifier-fixtures.md` says a fixture with a
`compiled` criterion supplies the compiler in `repo_root`, a stand-in or
the real one copied from the tree a sibling `gen/` directory resolves
to, and never relies on the fallback. The bootstrap gate lists `append`
as a reviewed false positive for `spec-bundle-assembler`.

## Consequences

Only `verifier-orchestrator`'s bundle changes; the rest of the #12/#13
cascade regenerates after it as planned.
