# D389 — Lint and spec check report what they cannot read; a reply without markers is repaired

## Context

Three failures from the `D373`-`D388` round:

- `hotdocs lint` died with an `AttributeError` traceback on any project
  with a directory under `specs/components/` that has no
  `component.md`: `corpus-loader` gives such a component a `None` root,
  `size-checker` read its frontmatter regardless, and no rule reported
  the directory.
- `hotdocs spec check` died with a `PreconditionFailure` traceback when
  a criterion's bundle could not be built, as for `comp-ui-style` before
  the `css` kind's adapter existed.
- `test-author` intermittently failed its own criteria with
  `missing_file_markers`, each time on a criterion whose test builds a
  stand-in reply with nonce markers, and never when retried. A model
  writing such a test may wrap its own reply in its test's example nonce.
  The failure gave no repair chance and kept none of the reply.
- `hotdocs author-test` always failed with `expected <component-id> and
  <criterion-id>`: its `VerbTable` row stripped no tokens, so
  `test-author`'s `main` (`R-AUTHOR-029`) got the verb word as a third
  positional. The routing hand suite sent only an unknown flag, which
  every `main` rejects before counting positionals. Behind that, its
  `main` let an unknown component id escape as a traceback.

## Decision

- `R-LINT-037`: such a directory is one `fail` finding, and `R-SIZE-001`
  skips a component whose root is `None`.
- `R-REVIEW-009`: a bundle that cannot be built is a `bundle_unavailable`
  finding for that criterion; `spec check` exits `1` and goes on.
- `R-AUTHOR-009`/`R-AUTHOR-027`: the reply instruction says the marker
  lines use exactly this call's nonce and that a test builds its own
  markers from the nonce it reads when it runs; a reply without markers
  is repaired like a test the probe rejects; the final failure's message
  starts with the reply's first 200 characters, so the next occurrence
  can be diagnosed.
- `test-author-output.md`: a bundle `main` cannot build is one stderr
  line and exit `1`, never a traceback.
- `VerbTable`: `author-test` strips `1`. The routing hand suite also
  routes valid positionals through the real dispatcher.

## Consequences

Regenerated: `size-checker`, `spec-linter`, `test-author`, `spec-reviewer`,
`hotdocs-cli`.
Their dependents re-verify their committed code (`D379`).
