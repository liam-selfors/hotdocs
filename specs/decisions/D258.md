# D258 — A data example that is not a JSON object declares no fields

## Context

Seed 27 of `criterion-compiler` crashed on an `interface/data/` file
whose `json` example did not parse, failing `AC-COMPILE-008`, which
allows a compile error but not a crash. The library notes said a type's
fields are its first example's keys and nothing about an example that
has none.

## Decision

Such a type is declared with no fields. A step naming one of its fields
then fails to resolve, a compile error under `R-COMPILE-002`.

## Consequences

`criterion-compiler` is regenerated.
