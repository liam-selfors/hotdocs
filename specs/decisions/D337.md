# D337 — agentic-generator's criteria pin the sandbox's limits and error flags

## Context

`agentic-generator`'s first generation on the merged specs passed every
criterion on five seeds but scored 0.75 to 0.78 against the 0.8 mutation
bar. The surviving mutants changed rules `R-AGENT-003` states through
`specs/architecture/agent-sandbox.md` that no criterion exercised: the
200-file limit, rewriting a file at that limit, `write_file` making
nested parent directories, a directory given to `read_file`, the
8192-character cut, and the `is_error` flag of a successful or failed
call.

## Decision

New criterion `AC-AGENT-009` covers `R-AGENT-003` with exact
`(text, is_error)` pairs for those cases, and for a successful
`check_import` run without an OS sandbox when `allow_unisolated_exec`
is true. No requirement or rule changes.

## Consequences

Only `agentic-generator` regenerates; its bundle hash does not include
acceptance files, so nothing else misses.
