# D224 — `complete()` returns an injected backend's exception as a classified `model_call_error`

## Context

Seed 4 of `llm-endpoint` failed two criteria. `AC-ENDPOINT-003` injects
a backend that raises a rate-limit error and expects a `model_call_error`
of category `rate_limit`; the candidate let the exception escape, and so
did the hand-written version, which passed an injected backend's result
through untouched. The interface only described a backend that returns a
`ModelResponse`. The other failure was a test importing a helper module
that does not exist, a test-author error.

## Decision

`interface/library.md` says `complete()` raises nothing but
`ModelResolutionError`: an injected backend's exception comes back as a
`model_call_error` classified the way HTTP failures are, with no retry.

## Consequences

The regenerated `llm-endpoint` also stops a misbehaving test backend from
crashing its caller, which the hand-written one did not.
