# R-GEN-004

**R-GEN-004** — The model identifier MUST be an explicit parameter, never
  hardcoded to "the canonical pin," and MUST be passed through to
  `llm-endpoint` (`D18`) unchanged. Credential resolution for whichever
  vendor that identifier names is `llm-endpoint`'s own job
  (`R-ENDPOINT-002`) — this component no longer resolves a vendor or
  holds a credential itself.
