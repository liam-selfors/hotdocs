# R-UI-002

**R-UI-002** — MUST render every node in the currently-selected scope
  (`R-UI-007`), colored by its current provenance status — a direct
  render of `provenance-tracker`'s `check_readiness` result
  (`VerifyReport`, `D88`), never a recomputation of anything it already
  decided. A component or capability node MUST be visually
  distinguishable across at least: passing (hit, verification/
  capability-scenario report both pass), failing (hit, but a failure
  recorded), and missing (a miss — never attempted, or stale).
