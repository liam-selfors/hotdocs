# R-UI-002

**R-UI-002** — MUST render every node in the snapshot, each with the
  `status` `TrackerSnapshot.md` defines — a direct mapping of
  `provenance-tracker`'s `VerifyReport` fields (`D88`), never a
  recomputation of anything it already decided. The four statuses
  (`passing`, `failing`, `missing`, `not-attempted`) MUST each carry
  their own `status-<status>` CSS class and the tone class
  `specs/architecture/visual-style.md` "Tones" maps it to
  (`passing` `tone-ok`, `failing` `tone-fail`, `missing` `tone-warn`,
  `not-attempted` `tone-neutral`), besides `node`,
  and the node element's `data-status` attribute MUST equal the
  snapshot's `status` for that node.
