# R-UI-003

**R-UI-003** — This component MUST NOT implement a "generate" action of
  its own. Running `hotdocs generate` is already the complete recovery
  path for a failing or missing component; this component's job ends
  at making it obvious, from the rendered view, which nodes still need
  it — not at triggering it itself. A future convenience button that
  shells out to the same CLI command a developer would type anyway is
  a plausible later addition, not a gap in this version.
