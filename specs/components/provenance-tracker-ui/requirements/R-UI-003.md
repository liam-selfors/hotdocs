# R-UI-003

**R-UI-003** — This component MUST NOT implement a "generate" action of
  its own. Running `hotdocs generate` is already the complete recovery
  path for a failing or missing component; this component's job ends
  at making it obvious which nodes still need it. The page MUST contain
  no `<form>`, no link whose `href` leaves the page, and no script that
  does anything beyond showing, hiding, or selecting content already in
  the page: its one script, `static/app.js` (`R-UI-001`), only filters
  nodes by status (`R-UI-010`). The `tracker-snapshot` JSON block
  (`R-UI-002`) is data, not script: its text, including `not_ready_reasons` that may themselves
  say "run hotdocs generate", is copied verbatim and is not an action
  (`D161`). A future convenience button that shells out to the same CLI
  command a developer would type is a plausible later addition, not a
  gap in this version.
