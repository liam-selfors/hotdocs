# R-UI-010

**R-UI-010** — The page MUST offer five filter buttons, in this order,
  each `<button type="button" data-filter="<f>">` with visible text:
  `all` (`all`), `passing` (`passing`), `failing` (`failing`),
  `missing` (`missing`), `not-attempted` (`not yet attempted`). On
  load every node is shown. Clicking a button hides exactly the node
  elements the asset's `hiddenByStatus` (`interface/assets/app.js.md`)
  reports `true` for that button's `data-filter`, and shows the rest:
  `"all"` shows every node, any other filter shows only the nodes
  whose `data-status` equals it.

  Every decision is made in `hiddenByStatus`, a pure function over
  JSON, so criteria test it through `asset_runner`; `init(document)`
  only wires the buttons to it (`D343`), which criteria check on the
  rendered page through the `browser` driver (`D373`).
