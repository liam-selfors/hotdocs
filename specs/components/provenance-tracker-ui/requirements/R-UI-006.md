# R-UI-006

**R-UI-006** — The written `index.html` MUST render correctly opened
  directly from `file://`, with no server of any kind. Every datum is
  already inlined (`R-UI-001`), so nothing is fetched at view time and
  the browser CORS restrictions that once motivated a local server
  (`D16`) never arise. `hotdocs track ui serve` is retired (`D154`);
  this component starts no process and leaves nothing running.
