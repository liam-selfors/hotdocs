# R-UI-005

**R-UI-005** — A component that is a provenance miss and has no
  `AttemptRecord` at all (never touched by `hotdocs generate`) MUST
  render with status `not-attempted` and the visible label "not yet
  attempted" — distinct from `passing`, `failing`, and `missing`, never
  an error and never a blank or unlabeled node. A missing or empty
  `.hotdocs/attempts/` directory is the normal fresh-checkout state,
  not a failure: `render_tracker_ui` still writes the page. Same "never
  silent" posture this corpus applies to every other absence-vs-failure
  distinction (`R-LINT-015`'s skip-vs-fail handling).
