# R-UI-005

**R-UI-005** — A node with no provenance recorded at all yet (never
  touched by a `hotdocs generate` run) MUST render as an explicit "not yet
  attempted" state, visually distinct from both "passing" and
  "failing" — never as an error or a blank/unlabeled node with no
  explanation. Same "never silent" posture this corpus applies to
  every other absence-vs-failure distinction (the original
  brainstorm's model-availability posture, `R-LINT-015`'s skip-vs-fail
  handling).
