# R-UI-009

**R-UI-009** — `main(argv)` MUST implement `interface/cli.md` exactly,
  with `argv` beginning `["track", "ui", "build", ...]`: `--changed`
  (repeatable or comma-separated), `--repo-root`, `--out` (default
  `<repo-root>/.hotdocs/ui/`), `--model`, `--seed` (both passed to
  `check_readiness` as `model` and `seed`). Each flag accepts
  `--flag=value` or `--flag value`. Exit `0` once the page is written
  and its path printed; `1` when an existing JSON input fails to parse;
  `2` on a usage error (per `interface/cli.md`), a missing
  `corpus-graph.json`, or `provenance-tracker`'s own `UsageError` (the loaded module's
  `UsageError` attribute, a class distinct from any defined here).

  Covered from the start: three other components' CLIs went uncovered
  until mutation testing exposed them (`D130`, `D136`, `D145`).
