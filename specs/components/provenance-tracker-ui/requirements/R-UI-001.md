# R-UI-001

**R-UI-001** — `render_tracker_ui` MUST write exactly one
  self-contained `out_dir/index.html`: the full `TrackerSnapshot`
  (`interface/data/TrackerSnapshot.md`) inlined once as JSON, plus
  CSS and the asset `static/app.js` (`interface/assets/app.js.md`)
  inline in the same file. No external
  script, stylesheet, image, or font reference; no `fetch`,
  `XMLHttpRequest`, `import`, or WebAssembly outside the asset, whose
  layout check forbids them (`D154`).
  Every query happened at build time; the page only renders.

  The inlined block MUST be exactly this element, with any `</` inside
  the JSON written as `<\/` so it cannot close the tag early:

  ```html
  <script type="application/json" id="tracker-snapshot">{...}</script>
  ```

  Each node MUST render as one flat element directly carrying its own
  identity and status, never under a per-node heading (`D150`/`D153`),
  and MUST be present literally in the written `index.html` — rendered
  in Python at build time, never constructed by JavaScript at view
  time. JavaScript may only show, hide, or select elements already in
  the file:

  ```html
  <li class="node status-missing" data-node-id="comp-bar" data-kind="component" data-status="missing">
  ```

  The page's only JavaScript is that asset (`D343`): `render_tracker_ui`
  reads `Path(__file__).parent / "static" / "app.js"` (the asset sits
  beside the flat module, at `gen/provenance-tracker-ui/static/app.js`)
  as UTF-8 and writes it exactly once, unchanged, as the element
  `<script type="module">` + its text + `\ninit(document);\n` +
  `</script>`. The Python code holds no JavaScript of its own; the
  asset follows `specs/architecture/asset-kind-javascript.md`'s generator guidance.
