# R-UI-008

**R-UI-008** — For a component node with status `failing` or
  `missing`, the page MUST show its `AttemptRecord` history (one
  element per attempt carrying `data-attempt-id`, oldest first) and,
  when its `retry_feedback` is non-empty, a ready-to-copy suggestion
  in an element with class `retry-feedback` whose text is exactly
  `--retry-feedback=` followed by the `R-id`s joined with commas (e.g.
  `--retry-feedback=R-BAR-002`). This is the same information
  `last_requirement_failures` returns, attached to the node instead of
  requiring a separate lookup. It is never auto-filled into anything
  or acted on (`R-UI-003`): a developer reads it and chooses to pass it
  to `hotdocs generate`.
