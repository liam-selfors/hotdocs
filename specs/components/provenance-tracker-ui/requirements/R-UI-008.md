# R-UI-008

**R-UI-008** — For a component node that is currently failing or
  missing provenance, drilling in MUST show its `AttemptRecord` history
  and `last_requirement_failures` (`provenance-tracker`'s `R-TRACK-008`)
  as a ready-to-copy retry-feedback suggestion — the same information
  `hotdocs track feedback` prints, shown here attached to the node
  instead of requiring a separate CLI lookup. Never auto-filled into
  anything or acted on automatically (`R-UI-003`) — a suggestion a
  developer reads and chooses to pass to `hotdocs build
  --retry-feedback`, same discipline as the CLI convenience it mirrors.
