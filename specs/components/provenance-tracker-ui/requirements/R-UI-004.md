# R-UI-004

**R-UI-004** — `render_tracker_ui` MUST read exactly four sources:
  `provenance-tracker`'s `check_readiness` (status), its
  `last_requirement_failures` (retry feedback),
  `<repo_root>/verification/corpus-graph.json` (topology, committed),
  and `<repo_root>/.hotdocs/attempts/<component_id>/*.json` (history,
  local-only). It MUST NOT read anything else under `specs/`, `gen/`, or
  `verification/` directly, besides its own asset `static/app.js`
  (`R-UI-001`), and MUST write nothing except
  `out_dir/index.html` (Python's own `__pycache__` bytecode, written by
  the interpreter when a dependency module is imported, is not this
  component's write).

  Committed topology and local-only provenance are still read
  separately and never conflated (`D10`); the page itself stays
  local-only and per-developer even though one input is committed,
  CI-rendered data.
