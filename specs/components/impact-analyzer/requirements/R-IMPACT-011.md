# R-IMPACT-011

**R-IMPACT-011** — `hotdocs impact` MUST parse its arguments, print its
  output and exit exactly as `interface/cli.md` states: `--changed`'s
  token rules, both value forms of `--repo-root` and `--format`, the
  text output's line format, and exit `0` on a computed report, `1` on a
  precondition error (in either format, printed to stdout), and `2` on a
  usage error, which prints nothing to stdout.
