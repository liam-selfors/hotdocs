# R-LINT-027

**R-LINT-027** — Every `` `<file>`'s "<Section>" section `` pointer in a
  live document MUST resolve: the file MUST exist, and MUST contain a
  heading matching `<Section>` exactly. Whitespace inside the backticks,
  a hard wrap included, is removed first; a path starting with `<` is a
  placeholder, not a pointer (`D222`).
