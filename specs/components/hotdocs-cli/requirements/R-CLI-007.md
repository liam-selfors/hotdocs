# R-CLI-007

**R-CLI-007** — When the arguments after a matched row's verb words hold a `--help` or `-h` token, `run` MUST answer with that verb's help (`D363`). The row is dispatched as `R-CLI-001`, `R-CLI-002` and `R-CLI-005` say, with two differences: `R-CLI-003` is not applied (`load_config` is not called, no token is injected or removed, no `using model` line is printed), and everything written to `sys.stderr` while the component runs is captured, not shown. When the component returns `2` and the captured text's first line starts with `usage error:`, which is how a component that defines no `--help` answers one (`cli-conventions.md`), `run` MUST pass to `output_fn` the line `hotdocs <verb words>: <summary>`, with the row's verb words and summary, then each later non-empty captured line, in order, one call per line, and return `0`. Otherwise the captured text MUST be written to `sys.stderr` unchanged and the component's code returned, so a component that answers `--help` itself is passed through.
