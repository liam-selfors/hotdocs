# R-CLI-003

**R-CLI-003** — For a row whose `model` is `required` or `optional`, a `--no-model` token among the arguments MUST be removed from the forwarded tokens, and then nothing is injected. Otherwise, when the arguments hold no `--model` token (`--model` or `--model=...`) and `load_config(<repo root>/hotdocs.toml)` (`load_config` of `gen/llm-endpoint/llm_endpoint.py`, found as `R-CLI-001` finds a module) returns a provider and model, `--model=<provider>:<model>` (a model string, per the glossary) MUST be appended last, after the `--repo-root` token `R-CLI-002` may have appended; for an `optional` row, the line `hotdocs: using model <provider>:<model> from hotdocs.toml (pass --no-model to skip)` MUST also be printed to stderr before the component runs. The `using model` line MUST NOT be printed for any other row: a `required` row gains the token silently. If `load_config` raises `ValueError`, its message MUST be printed to stderr as one line, exactly `str(error)`, nothing is injected, and the component MUST still run with the remaining forwarded tokens, `main` returning its code. Nothing is injected otherwise: an explicit `--model` passes unchanged, and rows whose `model` is `no` never consult `load_config`, never gain a `--model`, print nothing about a model, and forward a `--no-model` token unchanged.
