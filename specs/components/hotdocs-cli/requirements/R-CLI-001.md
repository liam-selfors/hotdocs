# R-CLI-001

**R-CLI-001** — A verb MUST be dispatched to the row of `interface/data/VerbTable.md` whose verb words are the longest prefix of `argv`: the component's `main` is called with exactly `argv[strip:]` (never `argv[len(words):]`: a `strip` of `0` keeps the verb words, so `generate x --flag` calls `main(["generate", "x", "--flag", ...])`; the `init` row, whose `strip` is `1`, receives the tokens after `init`, with every following token kept), and its return value is the exit code (`None` is `0`). A `SystemExit` raised by the component MUST be caught and its code returned (`None` is `0`, a non-integer is `1`). A module is `<dir>/<module>.py` under the repo root, loaded by file path under a name unique to that repo root and registered in `sys.modules` before it runs; a module with a `.`, such as `docs_site_renderer.cli`, is imported with `<dir>` first on `sys.path`, every `sys.modules` entry for its package removed before and after. A module MUST be loaded fresh on every call and not left behind: a later call in the same process for another repo root never sees it.
