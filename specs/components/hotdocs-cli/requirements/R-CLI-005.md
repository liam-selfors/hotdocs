# R-CLI-005

**R-CLI-005** — The `init` row is special. Its module MUST be loaded from `<tool_root>/<dir>`, not from the project, since the project does not have it yet; no `--repo-root` is appended and `VAR_HOTDOCS_CONFIG` is not set; and in place of `main` its `run` is called, exactly `run(<remaining tokens>, tool_root=..., input_fn=..., output_fn=..., env=..., cwd=...)` with the values this component's `run` itself received, defaults filled in (`hotdocs-init`'s `interface/library.md`). A module with no `run` is not available, as `R-CLI-004` says of `main`. Its return value is the exit code, as for any verb.
