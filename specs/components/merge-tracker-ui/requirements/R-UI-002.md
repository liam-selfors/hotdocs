# R-UI-002

**R-UI-002** — MUST show, per component appearing in any of the most
  recent `N` tracking records (`N` a user-adjustable view parameter, not
  a fixed cap in this component's own logic), its outcome across those
  records in chronological order — whether each attempt was a cache hit,
  how many generation attempts it took, and whether it reached
  verification or stopped at `model_call_error`. This is a direct render
  of `TrackingRecord.components`, not a recomputation of anything
  `merge-tracker` already decided.
