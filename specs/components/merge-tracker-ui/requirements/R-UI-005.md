# R-UI-005

**R-UI-005** — An empty or missing `.hotdocs/tracking/` directory (no
  merge has run yet on this checkout) MUST render as an explicit "no
  attempts recorded yet" state, never as an error or a blank page with no
  explanation — same "never silent" posture this corpus applies to every
  other absence-vs-failure distinction (D10's model-availability posture,
  `R-LINT-015`'s skip-vs-fail handling).
