# R-UI-004

**R-UI-004** — This component MUST NOT read `specs/`, `gen/`,
  `verification/`, or `corpus-graph.json` — its only data source is
  `.hotdocs/tracking/`. Mixing committed corpus state into a local-only,
  gitignored view's rendering would blur a boundary `SPEC_GUIDELINES.md`
  §1 draws deliberately: this component's output must never be mistaken
  for, or accidentally depended on as, anything that reflects the actual
  spec corpus.
