# R-UI-003

**R-UI-003** — This component MUST NOT implement a "retry" or "resume"
  action of its own. Re-running `hotdocs merge` is already the complete
  recovery path (`R-MERGE-018`); this component's job ends at making it
  obvious, from the rendered view, which components still need a spec
  fix before that re-run — not at triggering the re-run itself. A future
  convenience button that shells out to the same CLI command a developer
  would type anyway is a plausible later addition, not a gap in this
  version.
