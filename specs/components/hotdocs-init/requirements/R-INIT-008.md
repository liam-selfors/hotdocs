# R-INIT-008

**R-INIT-008** — When `init` creates `.secret-allowlist.json`, it MUST write it as the UTF-8 bytes of `json.dumps(doc, indent=2)` plus `"\n"`, where `doc` is `{"version": 1, "entries": [E]}` and `E` is `{"file": "gen/review-packet-builder/review_packet_builder.py", "type": "Hex High Entropy String", "hashed_secret": "sha1:2c74b2b5a39b54beae7d7c0e994feb84693a3466", "reason": "public-constant"}` (the vendored git empty-tree hash). In the same run it MUST create `specs/decisions/D<N>.md`, `N` one more than the highest `N` of an existing `specs/decisions/D<N>.md` (`1` when none), whose frontmatter holds exactly `id: D<N>`, `title: Seal the initial secret allowlist`, `status: ratified`, `owners: [project]`, `last_ratified_commit: hotdocs-init`, and `allowlist_sha256: sha256:<hex>`, `<hex>` the SHA-256 of the bytes written; its body is a `# D<N>` heading and one sentence saying the allowlist changes only with a new decision recording its hash (`D197`). Its line is `specs/decisions/D<N>.md: created`. When the allowlist exists it is skipped as `R-INIT-001` says and no decision is written.
