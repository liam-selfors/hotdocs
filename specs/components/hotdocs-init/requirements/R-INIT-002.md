# R-INIT-002

**R-INIT-002** — `init` MUST NOT copy the tool into the project: the tool's components stay under `tool_root` and are found there (`D199`). It MUST write `<dir>/.hotdocs-tool.json`, only when absent and otherwise left byte for byte, holding `{"tool_version": TOOL_VERSION}`, the module constant `TOOL_VERSION = "0.1.0"` matching `pyproject.toml`. Before writing or loading anything, even `R-INIT-001`'s skeleton or `llm-endpoint` (an import writes `__pycache__`), it MUST refuse, exit `1`, if `<dir>` is `tool_root` itself, or if `<dir>/gen` holds a directory whose name is also a directory directly under `<tool_root>/gen/` (a project component would shadow the tool's), listing each such `gen/<name>`.
