# R-INIT-002

**R-INIT-002** — `init` MUST vendor the tool: copy every directory directly under `<tool_root>/gen/` to `<dir>/gen/`, and `<tool_root>/pipeline/criterion-compiler` to `<dir>/pipeline/criterion-compiler`, skipping any `__pycache__`, and write `<dir>/.hotdocs-tool.json` with `tool_version` (the module constant `TOOL_VERSION = "0.1.0"`, matching `pyproject.toml`), `vendored` (the copied paths, relative, sorted) and `content_hash` (`"sha256:"` plus the hash over the copied files' relative paths and bytes in sorted order). Before writing anything, even `R-INIT-001`'s skeleton, it MUST refuse, exit `1` with the colliding paths listed, if a target path exists and is not listed in an existing stamp, or if `<dir>` is `tool_root` itself. A path listed in the stamp is skipped and reported, not recopied, and an existing stamp is left untouched, byte for byte: the stamp is written only when absent. Nothing `init` does MAY leave a `__pycache__` under `<dir>`: a module it loads from the project (`llm-endpoint`) is loaded with bytecode writing disabled, the previous setting restored afterwards.
