# R-INIT-004

**R-INIT-004** — Unless `<dir>/hotdocs.toml` exists (it is then kept and reported), or `--reconfigure` is given, `init` MUST configure the provider. If neither `--provider` nor `--yes` is given it asks, through `input_fn`, in this order: the provider (a name or its 1-based number in the printed list from `detect_providers`, default the first available, else the first listed; an unrecognised answer is asked again); the model (default its `suggested_model`; an empty answer with no default is asked again); the base URL, only if `needs_base_url` (default `default_base_url`, asked again if empty with no default); and the API-key environment variable NAME, for every provider except `claude-cli` (default `default_api_key_env`; empty means none). An empty answer is the default. With `--provider`, the values come from the flags and defaults and nothing is asked; with `--yes` alone, from the first available provider and its defaults, and with none available nothing is saved and `init` says so and carries on. `timeout_seconds` is never asked or passed. If `<tool_root>/gen/llm-endpoint/llm_endpoint.py` does not exist, nothing can be configured: `init` prints `provider not configured: gen/llm-endpoint is missing` and carries on.
