# R-INIT-005

**R-INIT-005** — Then, unless `--no-test`, `init` MUST call `check_connection` and print `connection ok` or `connection failed: <category>: <message>`; a `ValueError` from it MUST be printed as `connection failed: invalid: <message>`. After a failure it asks `Save anyway? [y/N]` (interactive) or saves and warns (`--yes` or `--provider`); on `n` nothing is saved. Saving MUST be `save_config(<dir>/hotdocs.toml, provider, model, base_url=..., api_key_env=..., auth=...)`, passing a keyword only when it has a value; `--auth` reaches `check_connection` as `auth=` too (`D322`); a `ValueError` from it is printed as `could not save: <message>` to stderr, nothing is saved, and `init` carries on. `init` never asks for, reads, prints, or writes an API key.
