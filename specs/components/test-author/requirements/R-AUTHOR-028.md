# R-AUTHOR-028

**R-AUTHOR-028** — The written and cached test file MUST begin with the
  line `# hotdocs-criterion: sha256:<hex>`, `<hex>` the lowercase hex
  SHA-256, computed from the bundle and never taken from the model's
  content, of the bundle's `criterion_text`, a newline, and its
  `requirement_text`, encoded UTF-8; the model's content follows on the
  next line. A first line of the model's content that already begins
  `# hotdocs-criterion:` is replaced, never repeated.
