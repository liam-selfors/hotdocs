# R-AUTHOR-001

**R-AUTHOR-001** — Given a criterion's Given/When/Then text, its `Covers:
  R-id`, the covered requirement's own text from `requirements/`, the
  target component's `interface/` content, and the glossary (a
  `CriterionBundle`, assembled by `spec-bundle-assembler`), this component
  MUST produce test code that exercises the component's public interface as
  described, asserting the criterion's `Then` clause.
