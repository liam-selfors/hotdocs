# R-SIZE-004

**R-SIZE-004** — A component's `Purpose` section MUST stay within a
  per-section word cap (warn above 80, fail above 150) — `SPEC_
  GUIDELINES.md` §3.4's "one paragraph" rule, checked mechanically.
  A long `Purpose` is several paragraphs disguised as one, the same
  signal `R-SIZE-003` gives for an oversized file.
