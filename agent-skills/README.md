# Agent skills

Instructions for a coding agent working in a project built with
`hotdocs`, in the Claude Code skill format (`<name>/SKILL.md`). They
ship with the tool; a project uses one by linking or copying it into
its own `.claude/skills/`.

- `hotdocs-asset-kind/`: define a new asset kind, or move a component's
  embedded non-Python text into a declared asset
  (`specs/architecture/asset-kinds.md`, `D340`).
